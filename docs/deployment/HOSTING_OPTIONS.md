## 三条路

### A. 维持现状：法兰克福 VPS + 宝塔

现在就是这条。能用，但：

- 宝塔带来的是 PHP / MySQL / FTP / 8888 管理端口，静态站一样都用不到，全是攻击面。
- 生产环境那个「每 5 秒 `git reset --hard` + `chown -R` 重写全部文件」的循环，
  就是面板生成的脚本造成的（见 runbook §2）。缓存被它打成 0，排查花了不少时间。
- 上线延迟受轮询间隔限制，当前定为 5 分钟。

### B. Cloudflare Pages（对纯静态站的推荐解）

| 维度 | A（VPS+宝塔） | B（CF Pages） |
|---|---|---|
| 费用 | 服务器月租 | 本项目体量内免费 |
| 上线延迟 | 5 分钟轮询 | push 后约 1 分钟，事件驱动 |
| 全球速度 | 法兰克福单点 | 330+ 城市边缘节点 |
| HTTPS | 手动配置 | 自动 |
| 缓存头 | 手写 nginx（已踩过 `expires` 与 `add_header` 重复头的坑） | 平台默认已优化 |
| 运维面 | 面板需防爆破、需升级 | 无服务器可维护 |
| 统计 | 需自行部署 | 自带无 cookie 的 Web Analytics |

**唯一权衡**：中国大陆访问 Cloudflare 可能偏慢。本站目标客户是海外经销商与项目采购
（阿根廷、美国、欧洲），该权衡不影响业务目标；国内查看可保留现有法兰克福站做备份。

### C. 自建 VPS 但不装面板

若坚持自建：

- **镜像选 Debian 12 或 Ubuntu LTS。不要选 OpenCloudOS**（现服务器即是）——
  腾讯自研，社区文档少，排障时搜不到资料。
- **不装宝塔**。静态站只需 nginx + 一个带护栏的 `git pull` 定时任务。
- 真需要面板，**Caddy** 优于宝塔：单配置文件、自动 HTTPS、无管理端口。

## VPS 与云服务器

同一样东西的两种叫法。VPS 是物理机切分出的虚拟机；「云服务器」是在 VPS 之上加了
快照、弹性 IP、在线扩容等能力。腾讯云「轻量应用服务器」即简化版云服务器。
**对静态站两者无实质差别。**

「多买一台 VPS 分开部署」的收益是隔离与地理位置，但对静态站，
**CDN 比增加服务器台数划算得多**——CDN 是把站点复制到全球数百个节点，
多一台 VPS 只是多一个单点。

## 统计与 cookie

甲方问「带一个 cookies？」——**建议不要**。

用 cookie 就需要 GDPR 同意横幅，而首页已有促销弹窗；访客一进站两个框，体验很差。
**无 cookie 统计能拿到同样的访问量、来源、热门页面与停留数据**，且无需横幅：

- **Cloudflare Web Analytics** — 免费、无 cookie、一行代码；选方案 B 时自带
- **Plausible / Umami** — 无 cookie，可自托管于现有服务器

因此统计方案与托管方案绑定，建议先定托管再实施统计。
