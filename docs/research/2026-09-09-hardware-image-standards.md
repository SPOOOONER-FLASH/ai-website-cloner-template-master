## 五类配套的核对方法

| 用途 | 可以组合的逻辑 | 必须核实 |
|---|---|---|
| 欧规插芯锁 | 锁体、锁胆、拉手与对应锁片 | 背距、中心距、方轴、固定孔、凸轮、锁芯长度分配、门厚、开向；分体玫瑰盖与连板不可混为一谈 |
| 逃生门 | 具体推杠与对应外执手、锁体、锁芯 | 源资料指定的型号、功能与门条件；不得外推认证或替代逃生功能 |
| 管状/球形锁 | 原型号实际已带的两侧操作件、锁舌与配件 | 图中实物及随附清单；没有内部照片就不作爆炸拆解 |
| 夜锁 | 实际夜锁、锁盒和来源中出现的零件 | 内外侧配置、固定方式与实际供货件；不因“成套”而补造钥匙 |
| 玻璃门 | 具体夹具、转轴/地弹簧、拉手和锁夹配置 | 玻璃厚度、孔位、门重、上下安装关系、拉手固定方式；不能以同类目证明适配 |

表为选型检查框架，不是对任一 HYDE 组合的兼容认证。资料缺口不能由通用行业经验变成确定参数。

## 本轮纠正

1. **307 的外执手为015或9080E**，不是旧清单第1行的035；072已由最新目录补上独立记录与五张实物图（072-panic-exit-device-lock-case），已核对双欧规孔。共享目录新命名为 `015-panic-exit-device-trim`、`9080e-panic-exit-device-trim`、`035-panic-exit-device-trim`，不能因旧路径消失就断言型号没有照片。
2. **70BK不能从BK字样推定哑黑。** 主图是铜色，现有发布表面列表没有哑黑。本轮保持原图表面。其生成版固定孔深度与螺纹表现变化，退回；Blender改用原照片。
3. **AR4-110与普通110分别取源。** 本轮使用 `hyde-ar4-110-mortise-lock` 的专属图片和配置。
4. **LC04比例**：按已读尺寸图黑锁盒高173mm、深96mm，对照9004S执手135mm与玫瑰盖53mm，70SN标称总长70mm。场景中的不同透视不能用屏幕像素比直接证明实际装配；整套尺寸仍需以同一投影或原始工程数据核对。
5. **原厂混合结构的颜色保留。** 黑锁盒配银面板、红横杆配黑端壳、银色外件配彩锌内部件都依原图；不能为了“全同色”重涂实物。另行组合的可见饰面应按真实可供配置一致。

## 场景与验收

- 空间以石材、木材、浅灰墙面、样品盒、材料桌为主。每张明确主体，不增加无关五金。盒内泡棉是展示设计，不能默示为真实交货包装。
- 产品保持源图可见视角，不用重绘的背面支持所谓多角度。多角度来自实际图库。
- 验收顺序：型号 → 组件 → 孔/槽/螺纹/锁舌 → 比例 → 表面 → 抠图边界与透孔 → 接触阴影 → 构图。
- 任何机械特征重绘即退回严格产品发布；“候选”不等于已验收。本轮13张生成稿已全部退回并折叠存档，详见每图说明，不能上传替换产品页实物照片。
- Blender照片板只表示原照片进入可编辑场景。保留区RGB不变的断言验证的是像素处理，不验证实际尺寸、配套或CAD结构。对70BK仅移除连通白背景、独立角标，并调整现有1像素透明边界；没有重建五金。
