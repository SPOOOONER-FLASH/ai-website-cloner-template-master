## 一、AI 可引用性 54/100 —— 唯一真正的瓶颈

按页面类型全量实测（`scripts/audit-geo-citability.mjs`）：

| 页面类型 | 页数 | 得分 | 每页可引用数字 |
|---|---|---|---|
| Product Finder | 1 | **75** | 33.0 |
| `/compare/` | 15 | **68** | 18.7 |
| `/es/compare/` | 15 | 67 | 17.7 |
| FAQ | 2 | 66–69 | 3–5 |
| Company | 2 | 63–66 | 6–7 |
| News | 9 | 57 | 6.6 |
| **产品详情页** | **377** | **55** | **4.8** |
| `/es/` 产品详情 | 377 | 54 | 4.2 |
| `/collections/` | 19 | 38 | 1.1 |
| `/configurator/` | 2 | 35 | 0.0 |
| `/projects/` | 4 | 39 | 0.0 |

### 结论只有一条

**377 个产品详情页，平均每页不到 5 个可引用的具体数字。** 它们占全站
可索引页面的 88%，所以它们的分数就是全站的分数。

答案引擎引用的是**能脱离原页面独立成立的句子**，而带单位的数字是最强的引用
信号 —— 因为那是生成式回答不敢编、只能归因的东西。「视具体型号而定」被摘出来
就没用了；「多数型号在 300–5,000 件之间」搬到哪里都成立。

这与我们此前所有独立测量指向同一处：**装箱数据覆盖率 1%、循环寿命 23%、
中心距 33%**。补齐它们，377 个页面的分数会一起往上走；不补，任何标记层面的
改动都动不了这个数。

### 一个我修掉的测量错误，值得记下来

第一版把「包含数字的句子数」当作指标，结果报告说**对比页是全站最不可引用的页面
（1.3 个数字）**。对比页是规格表 —— 单锁舌那张表里有 20 个 mm 数值。表格没有
句号，整张表被并成一个 1,180 字符的「句子」，只算 1 次。

**那是仪器的问题，不是页面的问题。** 一份建立在它之上的报告会把人派去重写全站
证据最扎实的那批页面。改成直接数匹配项之后，对比页从倒数第一变成第二名。

## 三、结构化数据 90/100

单个产品页 **8 个 JSON-LD 块、11 种类型**：
`Product · Brand · PropertyValue · BreadcrumbList · ListItem · Organization ·
PostalAddress · ContactPoint · WebSite · EducationalOccupationalCredential ·
QuantitativeValue`。

FAQPage 双语齐备，且**标记与页面文字用同一个函数取数** —— 审计正是查这一条
（`jsonld-faq-answer-not-visible`），两边不可能漂移。

扣分：产品 schema 缺 `offers`（无价格）与 `aggregateRating`（无评价）。
这两个是刻意不做的 —— 我们不公开价格，也没有真实评价，编造它们会换来富媒体
展示和一次可被拆穿的声明。

**101 条外链，95 条锚文本是 `https://www.cantonlock.com/`，全部指向首页。**

这是站外事实，仓库里的任何改动都动不了它。唯一的杠杆是把那些 listing 改指
它们描述的产品页 —— 清单在 `docs/research/BACKLINK_DEEPLINKS.md`，38 条已配好

8/28 六次），其余日期为 0。基数极低，但不是零 —— 说明入口是通的，缺的是内容
密度。

## 五、平台覆盖 20/100

无 YouTube、Reddit、Wikipedia、LinkedIn 公司页存在。对制造业 B2B 而言这不是
致命项，但它是 AI 模型确认「这家公司是真实存在的实体」的主要旁证来源。

**有一个现成的机会**：甲方 2026-09-04 提供的逃生锁素材里含 **34 个产品视频**，
目前网站完全没有视频。YouTube 是 AI 训练语料里权重最高的视频源之一。

## 复核方式

三个脚本，每次发布可重跑：

```bash
npm run seo:graph       # 图谱：孤儿页、深度、重复、alt
npm run seo:deadlinks   # 死链（已是发布硬门禁）
npm run seo:bing        # Bing 七条发现逐条对照
node scripts/audit-geo-citability.mjs   # 本报告的可引用性表
```

**这份报告的每一个数字都能重跑得到。** 没有一处是估的。
