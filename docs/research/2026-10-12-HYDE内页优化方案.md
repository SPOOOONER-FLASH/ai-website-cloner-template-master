# HYDE 内页优化方案：产品页、指南页（2026-10-12）

甲方 10-12：「借鉴远高的四合一 设计 产品 内页 和hyde的 其他页面有什么可以继续优化设计的，比如 产品页面 指南页 做预览让我看看」。

预览在桌面 `03-研究与方案\HYDE动效演示页-2026-10-12\index.html`，左下角切换「产品页 / 指南页」。用的是真实数据：产品页是 307，指南页是《Exit Device Comparison 2026》。源码在 `docs/design-references/2026-10-12-motion-demo/src/Inner.jsx`，数据由 `prep-inner.mjs` 从 content/ 读取。

## 一、现在的线上页面，先要修的问题（不改设计也该修）

| 页面 | 问题 | 改法 |
|---|---|---|
| 产品页 | 标题上方、视频下方、第二张图周围各有一大块空白，图片显得很小 | 图库改成一个主图框加一排缩略图，空白去掉 |
| 产品页 | 10 张图里只看得到 2 张，尺寸图（1010 max、970 max、孔距）埋在图库里 | 尺寸图和安装图单独成一节「Drawings」，点开可放大 |
| 产品页 | 卖点照抄原始资料：「Push Bar Features:」「1.」「• Lock Case: 072」混排 | 改成规格表，加一节「In the set」，列出 072 锁体和 015、9080E 外侧执手，配图并链接 |
| 产品页 | 规格表在第二屏右侧，排在按钮下面 | 首屏放四格规格（长度、材质、换向、起订量），完整规格表单独一节 |
| 指南页 | 首图带旧供应商红色标志：用的是 `/images/products/316-d…` 原图，不是 HYDE 版 | 改用 `products-hyde` 的同名图，预览里已改 |
| 指南页 | 「Before you specify」框是深绿色，不在黑白品牌色里 | 改成墨色细线框，或者直接去掉；预览用的是章节长度条 |

## 二、产品页：借了什么

| 段落 | 借自 | 做法 |
|---|---|---|
| 首屏 | **2** 购买区 + **4** 字体 | 左边大图，带 01/08 计数和左右箭头。鼠标移上去，按鼠标位置放大 1.8 倍，看清孔位和表面；手机上不放大。右边型号「307」特大字从遮罩里升起，下面四格规格、两个按钮、PDF 和阿里链接 |
| 分节导航 | **2** | 滚过首屏后吸顶，显示当前所在的节（规格 / 图纸 / 套装 / 视频 / 下单 / 指南），右端一直有「Request a quote」 |
| 章节 | **4** | 每节左边是固定不动的标题和一句说明，右边是内容 |
| 规格 | **4** 复制条款 | 表格逐行出现。没公布的行（表面代码、防火等级）写「— ask us」，不编数字。一键复制「型号 + 全部规格」，方便采购贴进招标文件 |
| 数字条 | **1** 数字条 + **4** 黑底升字 | 黑底三个大字：1000 mm 杆长、L / R 左右通用、50 pcs 起订，全部来自规格表 |
| 图纸 | 新增 | 尺寸图、安装图并排，点开全屏放大 |
| 套装 | **1** 示意图点亮的思路 | 套装实拍图，旁边列 072、015、9080E 三个配件，各自链接 |
| 下单 | **4**「告诉我们你的工况」 | 六项清单：型号和颜色、数量、门厚、门宽、外侧执手、目的国。一键发邮件（正文已填好），或一键复制 |
| 相关 | **4** | 引用 307 的 7 篇指南，加同系列 4 款，悬停时图片慢慢放大 |

## 三、指南页：借了什么

| 段落 | 借自 | 做法 |
|---|---|---|
| 封面 | **4** | 左边特大序号「43」（第 43 篇，共 45 篇），右边日期、阅读时长、节数、型号数、标题、带竖线的摘要、作者，再加一排文中提到的 11 款产品小图 |
| 章节长度条 | **3** | 每节一条，长度按字数，一眼看出全文结构；点一下就跳过去，读到哪一节哪条变黑 |
| 首图 | **4** | 大图，滚动时轻微视差 |
| 正文三栏 | **4 / 2 / 3** | 左边目录固定，显示「03 / 08 · 38% read」，当前节有黑条滑过去。中间是正文。右边是本文型号，**当前这一节提到的型号会亮起来** |
| 阅读进度 | **4** | 顶部细进度条只按正文算，右下角显示「About 4 min left」 |
| 表格 | **3 / 4** | 表格加编号「Table 1 · 9 rows」。第一列型号带小图，横向滑动时第一列固定。逐行出现。「not published」显示成灰色 |
| 引言 | **4** | 原文一句话放大成引言，一字不改 |
| 结尾 | **4** | 「■ End of guide」，下面是黑底的上一篇、下一篇，带图 |

## 四、不借的

和首页方案一样：

- 不做 3D 倾斜、悬浮合成图、客户名滚动墙、发光扫描线、模糊浮现的标题。
- 不接管浏览器滚动。
- 产品图只用实拍的 HYDE 版。

## 五、要你拍板

1. 产品页首屏的鼠标放大，要不要？好处是看得清孔位，代价是鼠标一移上去图就变。
2. 指南页的特大序号「43」，要不要？不要的话换成一行小字「Guide 43 of 45」。
3. 「Drawings」单列一节，图纸上的俄文「Рис.」要不要先清掉？图纸本身是原厂资料，尺寸不能改。
