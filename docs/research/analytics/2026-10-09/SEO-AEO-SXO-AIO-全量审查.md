## 二、AEO 答案引擎（谷歌精选摘要、AI 概览、语音答案）

1. **文章开头不先给答案**：82 篇里 46 篇的前两段没有任何数字、尺寸、型号或标准号，其中 25 篇连摘要都没有。答案引擎摘的就是开头，这是 AEO 最大的一个缺口。清单在 `docs/copy/article-openings-audit.md`。**归我**，按引用量从高到低改。
2. **FAQ 覆盖已经很宽**：5,467 页有 FAQPage 结构化数据。不再加量，只改质量（答案先给结论）。
3. **HowTo 只有 1 页**。锁芯长度计算、开孔、门厚这类“怎么做”的内容可以加 HowTo，但谷歌已基本不在搜索结果里展示 HowTo，**收益低，不建议做**。
4. **薄页面**（AI 引用能力得分低于 55）：联系、服务、活动、订阅、隐私、询价、认证、文件下载。其中**认证页和文件下载页**最该补：这正是“送审文件”话题 0% 的原因。只能写已确认的事实，现有报告多在客户名下，自有名下的 CE、ANSI 正在准备。**归我**，等 A5 买家提问原文到了一起改。

## 三、SXO 搜索体验（展示涨了，点击没跟上）

| 指标 | 现在 | 说明 |
|---|---|---|
| Google 展示（日均） | 2,884（上期 723） | 排名 10.7 → 8.3 |
| Google 点击率 | **0.87%**（上期 2.90%） | HS 编码指南一页 593 次展示、点击率 0.34%，拖低全站 |
| 桌面 LCP / INP / CLS | **3.6 秒** / 232 毫秒 / 0.16 | 目标 ≤ 2.5 秒 / < 200 毫秒 / < 0.1；手机 CLS 已在 r21 归零 |

1. **产品页标题偏长**：1,188 个产品页标题超过 60 个字符（英文 258、西 198、葡 159、俄 147、法 123、德 105、阿 105、土 93），在搜索结果里会被截断。最长 75 个字符。标题生成器归**工程会话**（`scripts/build-product-titles.mjs`）。建议把“型号 + 品类”放在最前面，厂名放最后，截断时丢掉的是厂名。
2. **指南描述偏长**：147 个指南和文章页（各语种合计）的描述超过 160 个字符，最长 262，会被截断。描述归**工程会话**，正文开头归我。
3. **视频页描述太短**：约 60 个视频页的描述只有 45 个字符左右。归**工程会话**。
4. **点击率实验 E1**：三篇指南的英文标题已改，10-14 读数。读数前不动那三篇。
5. **桌面 LCP 3.6 秒**：周报已列为工程 P1，查 /products/ 和产品查找器的首屏图。
