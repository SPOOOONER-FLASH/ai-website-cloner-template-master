# HYDE 动效四合一方案（2026-10-12）

甲方 10-12：远高四个方案里**最喜欢 4（品牌大片），其次 1（深海工程），3（数据驾驶舱）和 2（洁净科技）也有长处**，「你都借鉴 争取 四合一」。

这份方案定的是：首页每一段借哪个方案的哪种动效，按 HYDE 的规矩怎么改，先做哪些，哪些要你先拍板。四个方案的动效清单来自源码（`D:\clones yunagao 网站\d1-deep` … `d4-editorial`），每条都对得上组件文件。

## 一、骨架：以 4 号为主线，1、3、2 各取一段

| 首页段落（从上到下） | 借自 | 动效 | 按 HYDE 改成 |

## 二、不借的，和原因

| 不借 | 出自 | 原因 |
|---|---|---|
| 3D 倾斜卡片、跟鼠标转的产品 | 1、2 | 会让产品看起来变形；金属件的外形就是规格 |
| 漂浮产品棚拍合成图 | 2 | 实拍抠图配生成背景，09-24 你否过 |
| 客户名、项目名滚动墙 | 1、3 | 贴牌客户名称保密 |
| 扫描线、闪烁点、发光网格、青色渐变字 | 1、3 | 只是装饰，证明不了任何东西，还和黑白品牌冲突 |
| 标题从模糊里浮出来 | 1 | 首屏标题会晚出现，拖慢首屏时间 |
| Lenis 平滑滚动 | 四个都有 | 接管了浏览器自带滚动，触控板和读屏软件用起来别扭；多加约 16.5 KB |

## 三、怎么做（技术）

- **不装动画库**。远高四个方案都装了 `motion`（gzip 后约 49 KB）和 `lenis`。HYDE 用两样东西就够：
  - CSS 滚动驱动动画（`animation-timeline: view()`），放在 `@supports` 里。支持的浏览器（Chrome、Edge、新版 Safari）有动画；不支持的直接显示最终状态，不会坏。
  - 几个很小的客户端组件，只做必须要 JS 的事：轮播进度、跟手图、Sticky 故事的换图。
- **四条硬规矩**，每条都会写成测试锁住：
  1. 内容先在 HTML 里，动画只作用在已经显示的东西上。不允许 `opacity: 0` 等脚本来救（`SiteFacts` 出过数字卡在透明的事故）。
  2. 系统开了“减少动效”时，全部动画停掉，内容照常。
  3. 首屏大图和标题不能因为动画晚出现：上线前用 web-perf 量首屏时间（LCP），不能比现在差。
  4. 时长只用现有的 `--motion-*` 令牌，`npm run motion:check` 要过。
- 远高 3 号的视差和横向滚动没有处理“减少动效”。搬过来时会补上。
