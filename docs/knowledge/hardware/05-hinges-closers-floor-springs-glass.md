## 1. 是什么、怎么工作

这一族解决的是同一件事：**门绕哪根轴转，转完靠什么回来。**

```
承重与转轴：合页（hinge） / 天地轴（pivot）
回位动力：  弹簧（合页内弹簧 / 闭门器 / 地弹簧）
速度控制：  液压油 + 调速阀（closer / floor spring）；弹簧合页没有液压，只有弹力
```

### 1.1 合页（hinge）

逻辑链：门扇重量 → 门侧合页页片（leaf）→ 销轴（pin）→ 框侧页片 → 门框。门转动时，相邻两节合页管（knuckle）之间互相摩擦或经轴承（bearing）滚动。

| 类型 | 英文 | 怎么工作 | 我们的型号 |
|---|---|---|---|
| 平开合页 / 对开合页 | butt hinge（full mortise，两片都开槽嵌入） | 两片对称，一片嵌门边、一片嵌框；关门后两片几乎贴合 | SSH011–SSH022、SS026、SS027、BL027、BL028、B024、B025、Stainless Steel Door Hinge |
| 滚珠/轴承合页 | ball-bearing hinge（BB） | 节间压入轴承，钢球把节重压在淬硬钢滚道上，减少磨损（Hager） | SSH018 / SSH019（JSON：无轴承或 2BB 可选） |
| 子母合页 | flush / non-mortise hinge（行业俗称 butterfly） | 一片的轮廓从另一片挖出，关门后叠成一片厚度，**不开槽**直接装 | BL031 照片为此形式（黑色、带弹簧管） |
| 弹簧合页 | spring hinge（self-closing hinge） | 合页管内装扭簧，开门时上紧，松手回关；用调节孔加/减预紧 | SSH023、BL030、BL031 |
| 双向弹簧合页 | double-action spring hinge（café/saloon） | 两根弹簧管加一块中间片，门可向两侧开，回到中位 | SSH031（JSON：每侧 90°） |
| 旗形合页 | flag hinge | 一片带凸出的"旗"，常用于可拆门 | SSH017（JSON 标 Flag Hinge） |
| 暗合页 / 隐形合页 | concealed (invisible) hinge | 多节连杆藏在门边和框的深槽里，关门后完全看不见 | CH01（照片为多节连杆式） |
| 长合页 / 钢琴合页 | continuous (piano) hinge | 全长一根，负荷沿全长分布 | Piano Hinge |
| 弹簧合页销 | spring hinge pin | 管状弹簧芯，换进焊接式合页管，让金属门自关；配张紧杆 | SH02 |
| 门底弹簧轴 | spring pivot hinge（门底装） | 弹簧+阻尼盒嵌在门扇底部，地上一块角码作转轴，顶部另有天轴 | F100 SS、Wooden Door Floor Hinge |

**节数（knuckles）**：美标行业惯例是 5 节合页配平头帽（flat button tip），3 节合页配平齐隐藏帽（Hager）。节数是外观识别点，审图时同一扇门的所有合页节数必须一致。

**销轴（pin）**：可拆销（loose pin）可抽出卸门（BL028、SSH016 JSON 写 Loose Pin）；不可拆销（NRP, non-removable pin）在管上加一颗止付螺丝顶住销上的槽，螺丝只有开门才够得着（Hager）。这是外开门防止从外面拔销卸门的做法。

**压弯（swaging）**：页片在管根处有一个轻微错位。不压弯的合页（flatback）关门时两片间约有 5/16"（7.9 mm）缝；压弯后约 1/16"（1.6 mm）（Hager）。

### 1.2 闭门器（overhead door closer）

逻辑链（齿条齿轮式，rack and pinion）：

```
开门 → 臂（arm）转动主轴齿轮（pinion）→ 齿条活塞（rack piston）压缩主弹簧（spring）
     → 活塞另一侧的油经单向阀快速回流（开门轻）
松手 → 弹簧推活塞回程 → 油必须经调速阀（valve）的小孔回流
     → 阀开度决定关门速度；不同行程段由不同阀控制
```

液压控制分段（各厂角度不同，下列为常见描述）：

| 段 | 英文 | 作用 | 来源中的角度 |
|---|---|---|---|
| 缓冲 | backcheck（BC） | 开门过大角度时增加阻力，防止门撞墙 | 约 70–75° 起；平行臂约 85–90° 才起作用 |
| 主关门速度 | closing / sweep speed | 从全开关到接近门框 | dormakaba BTS 表述为 175°–15° |
| 锁舌速度 | latching speed / latch action | 最后一段加速或减速，让斜舌越过锁扣 | dormakaba：15°–0°；其他资料为最后 7–15° |
| 延时关门 | delayed action（DA） | 开到某角度后先慢慢停留再关 | 90° 模板约 70° 起 |

强度规格（power size）：EN 1154 把闭门器分为 EN1–EN7 七个力度级，每级对应最大门宽和门重（见 9.1）。可调力度闭门器标为一个范围，如 EN 2–5（Hager 5400 系列说明书即 2–5 可调）。

**三种安装方式**（idighardware；Hager 说明书）：

| 方式 | 英文 | 机身在哪 | 在门哪一面 | 关门状态下臂的姿态 |
|---|---|---|---|---|
| 标准臂 | regular arm | 门扇上部（靠合页侧） | **拉面（pull side）= 合页侧** | 主臂与门垂直、副臂（forearm）与门框垂直，臂伸出门面 |
| 平行臂 | parallel arm（PA） | 门扇上部 | **推面（push side）= 门挡侧** | 主臂与门框平行，贴近门头；需要门框下方的平行臂支座（PA bracket / shoe） |
| 顶框安装 | top jamb | 门框门头 | 推面 | 机身在框上，臂连到门扇；臂与门垂直伸出 |

平行臂会损失约一个力度级（读者经验，idighardware；可调力度的闭门器可补偿），所以同一扇门平行臂安装通常要选更大一级或调大力度。

### 1.3 地弹簧（floor spring）与天轴（top pivot）

逻辑链：

```
门的重量 → 门底夹/门底连接件 → 地弹簧主轴（spindle）→ 地弹簧机芯（埋在地面水泥盒 cement box 内）
门顶 → 天轴（top pivot / top centre）的销插进门顶连接件 → 门绕"主轴—天轴"这条垂直线转动
开门 → 主轴转动 → 机芯内凸轮/弹簧蓄能 → 松手后液压阀控制回关
```

- 单向（single action）或双向（double action）：双向门可往两边推，回到中位（BTS 80/75 V 两种都适用，dormakaba）。
- 常开（hold-open）：dormakaba BTS 75 V 有固定 90° 和固定 105° 常开两种型号，另有不带常开、改为延时关门的选择；**常开与延时关门二选一**。
- 主轴可换（interchangeable spindles）：用加长主轴解决门槛或地毯造成的离地高度变化；标准离地间隙通常为 8 mm（dormakaba BTS 资料）。
- 液压分段：CRL 说明书的地弹簧有两个独立调速阀，分别管前段和后段；dormakaba 分为 175°–15° 主关门和 15°–0° 锁舌段。

**我们的 D-/DZ- 系列要注意**：站上 D-1032、D-3001、D-3012、DZ-2039 等照片显示的是一个长方形机身，两端带安装耳，下面是一根不锈钢地面连接件，外形更像**嵌入门扇底部的门内式地弹簧**，而不是埋在水泥盒里的传统地弹簧；JSON 里"最小门厚 ≥42 mm / ≥60 mm"这一参数也只有在机身装进门扇时才有意义。是门内式还是地埋式，以及是否配水泥盒：**待核实**（问工厂，不要在文案里猜）。F101 照片则是标准的地埋式：长方形不锈钢盖板、中间方形主轴、下面是黑色盒体。

### 1.4 无框玻璃门夹（patch fittings）

无框钢化玻璃门本身不能开槽装合页，所以所有五金都以"夹"的方式夹住玻璃角部：

```
地弹簧主轴 → 门底夹（bottom patch，PT 10 类）的方孔 → 夹住玻璃下角
天轴销     → 门顶夹（top patch，PT 20 类）的轴孔   → 夹住玻璃上角
              ↑ 顶夹的轴可接：天轴（PT 24 类，装在门头/天花）
                              或亮窗夹（fanlight/transom patch，PT 30）
                              或亮窗+侧板夹（PT 40）
锁：         锁夹（patch lock）/ 地锁（bottom lock）/ 中锁（centre lock）/ 转角锁（corner lock）
```

GEZE 的系列图（Patch Fittings EN）列出：PT 10 门底夹（接地弹簧）、PT 20 门顶夹（接 PT 24 天轴或 PT 30/PT 40）、PT 30 亮窗夹带轴销、PT 40 亮窗+侧板夹、US 50 中锁、PL 50 锁夹、PL 55/PL 60 地锁。轴心到玻璃边距离 55 或 65 mm（±2.5 mm，GEZE PT 30 图；Bohle PT 10 同样可设 55 或 65 mm）。

我们照片里能对上的：F110 = 门底夹（方孔接主轴）；F111 = 带外伸轴销的夹（亮窗夹或门顶夹，安装方向**待核实**）；F112 = 两个轴套孔的长夹（用途**待核实**）；F113 = 小方夹（固定玻璃用的角夹，**待核实**）；F114 = 带 L 形连接板的夹（亮窗+侧板连接，相当于 PT 40 类）；F123 = 带欧式锁芯的玻璃门锁（锁体+锁舌）；GL125 SS = 免钻孔夹装式玻璃门锁。

## 2. 装在哪里、怎么装

### 2.1 门的类型和材料

| 产品 | 适用门 | 依据 |
|---|---|---|
| 平开/滚珠合页 | 木门、钢门（全开槽）；其他组合有半开槽、全明装、半明装 | Hager 四种安装形式 |
| 子母合页 | 轻型木门、室内门 | 不开槽，承重有限 |
| 弹簧合页 | 木门、金属门；SSH023 JSON 写室内门/商业门/防火门/走道门 | JSON |
| 门底弹簧轴 | 木门（F100 SS：≤80 kg） | JSON |
| 闭门器 | 木门、金属门、铝框门；不能直接装在无框玻璃上 | 行业通识 |
| 地弹簧 | 玻璃门（D-1031、D-1051、D-3015、D-3016、DZ-2031），木/金属门（其余） | JSON |
| 玻璃门夹 | 钢化玻璃，JSON 写 8–12 mm（F110–F123、F132），GL125 SS 为 8–10 mm | JSON |

**黄铜合页不能用在防火门上**，因为熔点低；钢和不锈钢合页可以（Hager）。

### 2.2 开门方向（handing）与推/拉面

- 合页的左右手：站在门的"外侧"（通常是上锁的一侧）看，门往里开、合页在右 = 右手（RH）；门往外开、合页在右 = 左手反向（LHRB）（Hager）。普通对称平开合页不分左右手，但带 NRP、弹簧、提升式的会分。
- 闭门器：标准臂装在**拉面**（门朝自己拉开的一面，也是合页节外露的一面）；平行臂和顶框装在**推面**（Hager、idighardware）。外门的闭门器装在室内侧，室内门装在不太显眼的一侧（idighardware）。
- 闭门器调速阀方向：标准臂安装时阀朝**合页边**；平行臂安装时阀**背离合页边**（Hager 5400 说明书）。阀朝向装错，常常就是机身装反了的信号。
- 地弹簧单向门要把机芯在水泥盒里往一侧挪（左/右手不同）；双向门机芯放在盒的中心（CRL 说明书）。
- SSH031 JSON 写 Non-Handed（Reversible）。

### 2.3 安装位置与尺寸

**合页数量**（Hager；与 NFPA 80 同）：每 30"（762 mm）门高一片，不足 30" 按一片计。

| 门高 | 合页数 |
|---|---|
| ≤60"（1524 mm） | 2 |
| >60"–≤90"（2286 mm） | 3 |
| >90"–≤120"（3048 mm） | 4 |

门宽超过约 37"（940 mm）可加一片分担对门框的拉力（Hager）。用弹簧合页时至少 2 片（Hager）。

**合页尺寸与门厚门宽**（Hager 表）：35 mm 门、≤813 mm 宽用 3-1/2"（89 mm）；45 mm 门、≤914 mm 宽用 4-1/2"（114 mm）；45 mm 门、914–1219 mm 宽用 5"（127 mm）；更厚更宽用重型 5"/6"。合页宽度 = （门厚 − 退边）× 2 + 所需让位，退边在门厚 ≤57 mm 时约 1/4"（6.4 mm）（Hager）。

**合页高度位置**：
- 北美常见口诀"5-10-居中"：上合页距门顶 5"、下合页距地 10"、中间居中——只在论坛二手引用中见到，**待核实**；Allegion 给出的是最小值：4-1/2" 与 5" 合页时门顶到上合页中心线不小于 5-3/8"。
- 英国防火门（JELD-WEN FD30 说明）：上合页距门顶 150 mm，下合页距地 225–250 mm，中合页居中，每扇 3 片。不同防火门的证书可能给不同范围，以门厂证书为准。

**闭门器**（Hager 5400 标准臂模板，开门 ≤120°）：机身孔位以合页中心线为基准，尺寸 A = 6-1/2"（165.1 mm）；开门 120°–180° 时 A = 4"（101.6 mm）。主臂装到主轴后与门垂直，调副臂长度让它与门框垂直，再把主臂预紧（preload）。平行臂：用扳手把主轴向合页侧转约 45° 再按 L/R 标记装主臂，调副臂让主臂与门框平行。**每个品牌模板不同，模板以产品说明书为准。**

**地弹簧**：
- 水泥盒顶面低于完成地面约 3 mm 安装（GEZE PT 10 图："Install cement box 3 mm under OKFF"）；另有厂家要求与完成地面齐平——按具体型号图纸。
- 盒体两个方向都要调平；灌浆时机芯在盒内，水泥不能进入机芯和盒之间（ASSA ABLOY 类说明书，经搜索摘要）。
- 用铅垂线让天轴销中心线与地弹簧主轴中心线在同一垂直线上（同上）。
- 机芯与盒之间的空腔用密封胶填，防潮（dormakaba 2300 sealing compound）。
- CRL：主轴到墙面的"背距"51 mm，装修后贴砖抹灰可减到 35 mm。

**玻璃门（GEZE 门夹系统数据）**：门扇最大 100 kg、宽 ≤1000 mm、高 ≤2800 mm，玻璃 ESG（钢化）8/10/12 mm；M6 螺丝拧紧扭矩不超过 15 N·m，M8 不超过 20 N·m。

### 2.5 门的加工

- **开槽合页**：门边和框各铣一个与页片同形、深度等于页片厚度的槽（mortise），螺丝孔要与页片沉头孔对齐。子母合页不开槽。
- **暗合页（CH01）**：门边和框各掏一个深矩形槽，深度略大于合页闭合厚度；JSON 给出 5 个规格（如 34×140×28 mm、16×70×11 mm），可推断槽的长、宽、深要对应规格（具体开槽尺寸**待核实**）。
- **闭门器**：门扇上 4 个机身孔、门框上 2 个臂座孔；木门用 #14 自攻螺丝，金属门钻孔攻 1/4-20 机丝（Hager）。门头上框（top rail）太窄装不下平行臂时要加托板（drop plate）（idighardware）。
- **地弹簧**：地面开坑放水泥盒；BTS 80 机身 341×78×60 mm，BTS 75 V 285×82×50 mm（dormakaba）。我们 F101 的 JSON：面板 308×108 mm，盒深 40.5 mm——坑要比这个略大，具体开坑尺寸**待核实**。门顶要装天轴，木门门顶开槽装天轴连接件（D-3010 系列体量见第 8 节）。
- **钢化玻璃**：**所有孔、缺口（notch）、磨边都必须在钢化前做完**，钢化后不能再加工。EN 12150-1 的一般建议：孔边到玻璃边 ≥2 倍玻璃厚，孔边到角 ≥6 倍玻璃厚，孔径不小于玻璃厚（Pilkington 资料，经搜索摘要）。门夹的缺口尺寸按门夹厂的开孔图，例如 D-3017 顶夹缺口 107×53.5 mm、D-3018 为 107×70.5 mm（JSON）。
- 门夹内衬：玻璃厚度不同用不同厚度的垫片，Bohle PT 10：8 mm 玻璃用 2×（2+1）mm，10 mm 用 2×2 mm，12 mm 用 2×1 mm。

### 2.6 必须配什么

| 产品 | 必须配 |
|---|---|
| 合页 | 足够数量、同型号同表面；配套螺丝；闭门器或弹簧合页时一般用滚珠合页（Hager：弹簧合页要配滚珠合页，不要配普通合页） |
| 闭门器 | 门挡（door stop，闭门器不能当门挡用）；平行臂要配支座；斜舌锁的锁扣让锁舌段速度能越过 |
| 地弹簧 | 天轴（top pivot / top centre）+ 门底连接件（木门）或门底夹（玻璃门）；盖板；必要时加长主轴 |
| 玻璃门 | 门底夹 + 门顶夹 + 天轴或亮窗夹；锁（地锁、中锁或转角锁）及对应锁扣；拉手 |
| D 系列顶夹 | D-1042 配 D-1031；D-1043 配 DZ-2031 / D-1051；D-3017 配 D-3015；D-3018 配 D-3016（JSON） |

### 2.7 常见安装错误

1. 合页数量不够、或三片合页不在同一轴线上 → 门下垂、销轴偏磨、锁舌对不上锁扣。
2. 合页槽太深 → 门"绑"在合页侧（hinge bound），关不严；太浅 → 缝大。
3. 闭门器装反面：拉面装成平行臂、推面装标准臂，或模板左右手用反。
4. 平行臂没开缓冲：dormakaba 说明书要求平行臂安装**必须**打开缓冲，缓冲起作用点会后移约 15°。
5. 调速阀拧得太松：Dexter 说明书警告不要从出厂位置逆时针多转两圈以上，会漏油；缓冲阀**永远不要完全关死**（Hager）。
6. 用闭门器当门挡，门被风或人推到机械极限。
7. 地弹簧主轴与天轴不在同一垂直线 → 门转动时上下"别劲"、关门位置漂移。
8. 水泥盒没调平、灌浆时水泥进机芯、没打密封胶 → 进水生锈。
9. 玻璃在钢化后钻孔，或门夹垫片厚度不对 → 玻璃爆裂或滑脱。
10. 防火门装了机械常开（hold-open）闭门器臂：防火门不允许机械常开，电磁常开需与火灾报警联动（idighardware）。

## 3. 场景和展示怎么做才对（审 AI 图规则）

### 3.1 必须成立

**合页**
- 合页只在**合页边（hinge stile）**，绝不在锁边；同一扇门的所有合页上下在一条垂直线上，同型号、同节数、同表面。
- 平开门关着时，从拉面能看到合页管（knuckle），从推面看不到合页（只看到门缝）。
- 门高约 2 m 的门：3 片合页；4 片只出现在更高的门（Hager 表）。
- 弹簧合页（SSH023、BL030）的管顶部有调力孔/调节销；双向弹簧合页（SSH031）是两根粗管，门可两向开。
- 暗合页（CH01）只在门开着时可见，门关上时完全看不到。

**闭门器**
- 标准臂：机身在拉面门扇上部、靠合页侧；关门时臂向外伸出成"Λ"形，臂座装在门头框上。
- 平行臂：机身在推面门扇上部；关门时主臂贴着门头框平行。
- 顶框式：机身在门框门头上。
- 机身只用在有门头框的门上；闭门器机身、臂、门、合页是同一扇门，同一表面色。

**地弹簧与天轴**
- 地面上**只看到一块盖板**，盖板与地面齐平或略低；主轴位于**合页侧门角下方**（轴心距门边约 55/65 mm 一类尺寸），不在门中间。
- 门顶同一垂直线上一定有天轴。
- 用地弹簧的门**侧边不应再有合页**。

**无框玻璃门**
- 玻璃厚度统一（10 或 12 mm 常见），边缘抛光，门是一整块钢化玻璃，无边框。
- 门底夹在下合页侧角，门顶夹在上合页侧角，二者在同一垂直线上；锁在下锁侧角（地锁/转角锁）或门中部（中锁）。
- 门上方若有固定亮窗（transom），亮窗玻璃底边有亮窗夹，其轴销向下插进门顶夹。
- 侧面有固定侧板时，用 L 形亮窗+侧板夹（F114 一类）连接。
- 门夹的金属盖板两面对称地夹住玻璃，玻璃边插进夹内，夹内可见黑/绿色衬垫边。

### 3.2 正常状态下看不到的东西

- 合页的销轴、轴承、弹簧（都在管内）；暗合页关门后整件不可见。
- 闭门器内部的活塞、弹簧、油；调速阀只在机身端面看到小孔或螺丝头（常被外罩盖住）。
- 地弹簧机芯、水泥盒、主轴在门关着时都看不见，只见盖板；门底夹的方孔看不见（被主轴插满）。
- 门内式地弹簧（我们 D 系列照片形式，**待核实**）装好后机身在门扇里，看不见。
- 玻璃上的钻孔和缺口被门夹盖板遮住。
- 转角锁/地锁的锁舌在锁上时伸进地面锁扣，从正面看不到。

### 3.3 物理上不可能、一票否决

1. 合页装在锁边，或一扇门的合页不在一条直线上、大小或颜色不一。
2. 无框玻璃门上装普通平开合页（玻璃不能开槽）——玻璃门用的是玻璃夹式合页或地弹簧+门夹。
3. 无框玻璃门上画着闭门器机身直接贴在玻璃上（没有任何连接板/门框）。
4. 地弹簧盖板出现在门中间、锁边，或门开着时盖板和门不在同一转轴上。
5. 用地弹簧的门顶上没有天轴，或天轴与地弹簧不在同一垂直线。
6. 门可以 360° 转一整圈（JSON 里写 360° 的型号也做不到——门会撞墙/框）。
7. 标准臂闭门器在推面、平行臂主臂垂直伸出、机身装在锁边。
8. 闭门器臂连到墙上或地上。
9. 双向开的门（地弹簧或双向弹簧合页）却画着门挡条（stop）挡在一侧。
10. 合页、门夹、闭门器混用两种表面色（如黑合页配不锈钢闭门器、镀金门夹配缎面不锈钢锁）。
11. 玻璃门门夹规格与玻璃厚度明显不符（夹缝远宽于玻璃，或厚玻璃塞进薄夹）。
12. 子母合页的两片在关门状态下仍分开、或装在开了槽的门边上。
13. 门夹拼出一个我们不卖的组合（AGENTS.md：不得拼"套装"）。

## 4. 功能和使用

### 4.1 功能分类

| 产品 | 功能 | 标准里的名字 |
|---|---|---|
| 合页 | 普通/重型；滚珠/普通轴承；可拆销/不可拆销（NRP） | EN 1935 分级 1–14；ANSI/BHMA A156.1 Grade 1/2/3 |
| 弹簧合页、弹簧轴 | 自关（self-closing） | ANSI/BHMA A156.17 |
| 闭门器 | 力度 EN1–EN7；缓冲、延时、常开、锁舌加速 | EN 1154；ANSI/BHMA A156.4 |
| 地弹簧 | 单/双向；90°/105° 常开或不常开；缓冲 | EN 1154（dormakaba BTS 资料写"floor spring tested to EN 1154"）；A156.4 涵盖 concealed floor closers |
| 玻璃门夹 | 门底夹、门顶夹、亮窗夹、侧板夹；锁夹、地锁、中锁 | 无单独夹类标准；玻璃按 EN 12150 |

**ANSI/BHMA A156.1 合页循环次数**（Hager 引用）：普通轴承 350,000 次；标准重滚珠 1,500,000 次；重型滚珠 2,500,000 次。

### 4.2 日常使用

- 闭门器调法顺序：先调主关门速度，再调锁舌速度，最后调缓冲/延时（Dexter、Hager）。dormakaba 建议门从 90° 关到闭合约 3–6 秒。
- 弹簧合页：用专用杆插进调节孔加预紧，再插销锁定；多片弹簧合页的预紧要一致。
- 地弹簧：常开型推到 90°/105° 会停住，再轻推越过即释放。

### 4.3 维护

- 合页：Hager 建议高频商用合页每年润滑一次；普通合页拔销涂锂基脂再打回；**不要用 WD-40 一类除水喷剂当润滑剂**；不要用研磨清洁剂或稀释剂擦表面。
- 闭门器、地弹簧：只调阀，不拆阀；漏油的闭门器一般不能补油，只能换（securityparts 关于 LCN 的说明）。
- 玻璃门：定期检查门夹螺丝扭矩和衬垫，防止玻璃滑移。

### 4.4 典型故障

| 现象 | 常见原因 |
|---|---|
| 门下垂、刮地、锁对不上 | 合页数量不够、规格太小、螺丝松、轴磨损 |
| 合页吱吱响 | 缺润滑；普通轴承磨损 |
| 门砰地关上 | 锁舌速度阀开太大；缓冲没开；油漏了 |
| 关门越来越慢/不稳 | 油位下降、混入空气、阀 O 圈老化（securityparts） |
| 门关不严 | 力度不够（平行臂少一级）、密封条阻力、锁舌段太慢 |
| 闭门器机身漏油 | 密封件失效或机身裂；一般整件更换 |
| 地弹簧门停不准中位 | 主轴与天轴不同轴；机芯没调到盒中心；进水锈蚀 |
| 玻璃门自爆/崩角 | 钢化后加工、孔距边太近、门夹垫片不对、夹紧扭矩过大 |
| 弹簧合页失去弹力 | 弹簧疲劳、预紧销脱落 |

### 5.1 各零件常见材料

| 零件 | 常见材料 | 我们 JSON 写的 |

| 合页页片 | 钢（易锈，适合室内恒温环境）、不锈钢（304/304L，可拉丝或抛光；强腐蚀环境用 316）、黄铜（不锈，装饰性好但强度低）（Hager） | 201/304 不锈钢、304、铁（BL027、IH01、Piano Hinge、F100 SS）、黄铜（B024、B025）、锌合金/304（CH01） |

**201 与 304 不锈钢**：201 用锰和氮替代部分镍（常见成分约 Cr 16–18%、Ni 3.5–5.5%、Mn 5.5–7.5%），304 约 Cr 18%、Ni 8–10%。多数资料认为 201 耐蚀性较低，适合干燥室内；也有腐蚀咨询机构认为在某些介质中两者接近。**磁铁测试不可靠**，确认牌号要材质证明或 XRF（machinemfg、hghouston，经搜索摘要）。我们多款合页写"201 / 304"——卖给潮湿、沿海或户外项目时，必须在报价时明确是哪一种。

### 5.2 工序（行业通识）

| 零件 | 典型工序 |
|---|---|
| 平开合页页片 | 板材落料冲压 → 卷管成节（knuckle rolling，Hager 提到"knuckle was rolled"）→ 压弯（swaging）→ 冲孔、沉孔 → 去毛刺 → 拉丝/抛光 → 着色（PVD、电镀、喷涂）→ 穿销、压轴承、铆帽 |
| 弹簧合页 | 同上 + 绕簧、热处理、装簧、预紧机构 |
| 暗合页 | 压铸（锌合金）或机加工本体 + 冲压连杆 + 铆接 |
| 闭门器 | 机身压铸 → 机加工缸孔和阀孔 → 齿条活塞、齿轮轴机加工/热处理 → 装弹簧、密封件、注油 → 装阀 → 机身喷涂；臂冲压 |
| 地弹簧 | 钢机身机加工 → 凸轮/主轴热处理 → 注油密封 → 水泥盒冲压防锈 → 不锈钢盖板冲压拉丝 |
| 玻璃门夹 | 底座冲压/铸造 → 不锈钢外罩冲压拉丝 → 衬垫裁切 → 装配 |

我们 JSON 对着色的表述：B 系列"PB/SB/AB/AC/CP"，SSH031 写"PVD"，BL030 写"Spray Coated"；具体每个颜色用的是 PVD、电镀还是喷涂，JSON 没写，**待核实**。

### 5.3 装配和测试

- 合页：转动顺滑无卡滞、销与管配合间隙、两片合拢间隙（压弯后约 1.6 mm，Hager）、螺丝孔与沉头匹配。
- 闭门器：每台注油后做泄漏检查、关门时间、各阀是否有效、力度档位；BHMA/EN 有循环测试（见第 9 节）。
- 地弹簧：主轴同心度、常开角度、密封、盖板平整度。
- 玻璃门夹：夹紧后玻璃不滑移；轴孔与轴销配合；锁舌行程。
- 我们 JSON 唯一的测试表述：F101 "Tested for over 500,000 open-close cycles"——是我们的说法，不是第三方认证，文案里不能写成"符合某标准"。

### 5.4 典型 QC 点

1. 合页页厚与报价一致（BL027 写 1.6 mm，SSH 系列 2.0–3.5 mm，差别直接关系承重）。
2. 孔位、孔数、沉头角度与样品一致；同批合页高度公差一致，否则三片不同轴。
3. 表面：同批颜色一致、无漏镀；201 件做盐雾或湿热抽检。
4. 闭门器：24 小时放置后无渗油；阀能调到底不脱出。
5. 地弹簧：常开定位可靠；主轴方头尺寸与门底夹方孔配合。
6. 门夹：衬垫厚度对应所标玻璃厚度；不锈钢外罩无划伤。

### 5.5 便宜货为什么坏

- 薄页片、铁材无防锈 → 下垂、生锈；普通轴承在重门上很快磨出间隙。
- 201 用在潮湿或户外 → 先于 304 出锈点。
- 闭门器密封件差 → 漏油，漏油后基本只能整台换。
- 力度不够的闭门器装在宽门上 → 关不严、锁不上。
- 地弹簧盒不防锈、不打密封胶 → 地面水进入机芯。
- 门夹衬垫薄、底座软 → 玻璃受力集中，崩角或滑出。

## 7. 演示怎么拍

只拍真实产品，真实动作，不做 CG 内部剖视（我们没有内部结构照片可对照）。

1. **合页对比**：同一门边并排装普通合页、滚珠合页，特写节间；手动转门，展示顺滑度。
2. **合页数量**：整扇 2.1 m 门全景，标出 3 片合页位置（顶、底、居中）。
3. **弹簧合页调力**：插调节杆转几格、插销锁定，松手门自关；再加两格对比关门速度。
4. **双向弹簧合页 SSH031**：门往两侧各推开 90°，松手回中。
5. **闭门器标准臂**：从拉面拍机身位置（靠合页侧）和 Λ 形臂；门全开松手，计时从 90° 到关闭，展示主速度段和最后锁舌段。
6. **缓冲**：快速推门，门在约 70–80° 明显变"重"。
7. **平行臂**（如做）：从推面拍主臂贴门头的状态，标注要用支座。
8. **地弹簧**：先拍地面只见盖板；再拍未装完的现场——水泥盒、调平、铅垂线对天轴；最后推到 90° 常开停住，再轻推释放。
9. **玻璃门**：从下往上拍门底夹—门顶夹—天轴同一垂直线；双向推门回中；锁舌落入地锁扣。
10. **散件铺陈**：用 f101-…-2 那种平铺方式拍全套，逐个标名。

### 8.6 JSON 中看起来不一致的地方（只标注，不修改）

1. **"最大开门角度 360°"**：D-3001、D-3012、D-3015、DZ-2031、DZ-2039、DZ-2086、DZ-2087。装在门上不可能转 360°；可能指机芯无限位、可自由转动——**待核实**后改写。
2. **"360° Rotation"**：BL031、IH01 合页。合页物理上做不到。
3. **F101 分类**：放在玻璃门夹，但照片、尺寸（面板 308×108、盒深 40.5 mm）和"可调锁舌速度"都是地弹簧特征。
4. **F132 分类**：55×60 mm 锌合金件，主图是圆柱形玻璃门拉手/拉手旋钮，不是门夹。
5. **F100 SS 表面**：材料写铁（Iron），表面写"Satin stainless steel (US32D)"。US32D 在 BHMA 体系里是缎面不锈钢（基材即不锈钢）的代号，铁件上只能是仿色——**待核实**后改写为实际工艺。另外它是门底弹簧轴，放在"brass-steel-hinges"。
6. **Wooden Door Floor Hinge**：名字写木门，`doorTypes` 却含 Frameless Glass；放在 door-closers 类；无规格。
7. **SSH018 / SSH019**："2BB Plain Bearing"自相矛盾——BB 指滚珠轴承（ball bearing），plain bearing 指无滚珠。
8. **BL030**：规格写 3.5 mm 厚，features 写"4”*3”*3”"，第三个数应为 mm；features 写"Soft Closing"，弹簧合页一般无液压阻尼，是否真有缓冲**待核实**。
9. **D-1042 与 D-1031 搭配**：顶夹写玻璃 10–12 mm，配套地弹簧写 10–14 mm；14 mm 玻璃能否用此顶夹**待核实**。
10. **JU-072 与 JU-073**：同为 40–65 kg，适用门宽却是 1050 mm 与 850 mm；如为同一力度机芯配不同臂，需说明，否则**待核实**。
11. **D/DZ 系列结构**：照片像门内式机身，JSON 和名称写 floor spring，无水泥盒/开坑尺寸，见 1.3。
12. **站点归属**：AGENTS.md 2026-09-23 记录"every floor spring is RAYEN-only"，现在这 19 个地弹簧及 9 个天轴/顶夹 JSON 的 `sites` 都含 `hyde`——以 JSON 为准，但相关分类摘要（`content/categories.json` 的 door-closer 摘要）是否已同步**待核实**。
13. **CH01**：功能写 Concealed hinge，应用写 Window Connection；照片是常用于门/柜门的多节连杆暗合页，应用描述**待核实**。
14. **6*3*3mm**：型号就是尺寸，"Anti Pry / Security Hinge"若指防撬钉（security stud），照片需能看到——**待核实**。
