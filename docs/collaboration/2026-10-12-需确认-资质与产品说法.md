# 2026-10-12 需要你确认：资质与产品说法（9 个问题）

**为什么问：** 指南和新闻末尾已经加上「相关产品 + 询价 + 下一步」区块。下一步是把资质放到产品旁边。但资质一旦写错，买家查证时会连带怀疑整个网站，所以下面每一条都要你确认后才写。

**这次已经删掉的：**
- 3 款产品写的「ANSI Grade 2/3」：028、5831 SSET、黑色管状执手锁套装。
- 300 / 307 / 310 写的「防火 1.5 / 2.5 小时」。
- 19 个产品各自挂的「ISO 9001」。ISO 9001 是工厂质量体系的认证，不是某个产品的认证。

删除的原因：网站在别处写着「没有 ANSI/BHMA 认证」「拿到证书编号之前不暗示防火等级」，前后矛盾。公司层面的「2002 年起通过 ISO 9001」保留没动。
