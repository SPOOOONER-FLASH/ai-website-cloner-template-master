# 服务器磁盘快满了：先查清楚是什么占的（2026-10-11，约 5 分钟，只看不删）

宝塔首页显示 `/` 用了 53.9 GB / 59.9 GB（89.86%），只剩 6 GB。满了以后服务器拉不了新版，网站就停在旧版。

**产品大脑不在服务器上。** 它在你电脑 `C:\Users\johns\Downloads\hyde-brain` 和 GitHub 私有仓库里，服务器上和它有关的只有一个几 KB 的登录页（还没上线）。所以不是大脑占的。

## 已经知道的（在我这边量的）

| 东西 | 大小 | 说明 |
|---|---|---|
| 官网的 git 历史（`.git`） | 约 9.3 GB | 已发布 321 次，每次发布都把整个网站文件存一份进历史，只增不减 |
| 网站文件本身（`out/` 5.6 GB、`public/` 1.6 GB、其他） | 约 8.2 GB | 服务器只需要 `out/` 和 `out-rayen/`，`public/`、源码其实用不上 |
| 合计一份 | 约 17.5 GB | 剩下约 36 GB 是什么，要你在服务器上看一眼 |

## 要你做的：贴 4 条命令，截图发我

1. 打开宝塔面板 → 左边 **终端**（或用 SSH 登录服务器）。
2. 一条一条粘贴，每条回车后**等它自己结束**（可能要 1–2 分钟，期间没有任何输出是正常的）：

```bash
df -h /
```

```bash
du -sh /www/wwwroot/cantonlock.com/.git /www/wwwroot/cantonlock.com/out /www/wwwroot/cantonlock.com/out-rayen /www/wwwroot/cantonlock.com/public 2>/dev/null
```

```bash
du -xh --max-depth=2 /www 2>/dev/null | sort -h | tail -20
```

```bash
du -xh --max-depth=1 / 2>/dev/null | sort -h | tail -12
```

3. 每条结果截一张图，四张一起微信发我。

**成功的样子**：每条命令都打出几行「大小 + 路径」，最后一行是最大的。
**这四条只读大小，不删、不改任何东西，网站不受影响。**

## 先别做的

- **宝塔里「立即清理」先别点。** 它会清日志和缓存，一般没事，但不同版本也会动回收站和备份；等我看了截图，告诉你哪些能删。
- 不要手动删 `/www/wwwroot/cantonlock.com` 里的任何文件夹，删错网站会直接打不开。

| 如果大头是 | 办法 | 能省 |
