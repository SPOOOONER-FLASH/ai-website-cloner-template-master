# 网站没更新到新版：服务器上查一下自动拉取（约 5 分钟）

**这份 Word 由仓库里的同名 markdown 生成，改内容请告诉我，不要直接改 Word。**

## 发生了什么

10-10 的新版本（产品查找器多语种跳转修复、AR-4 小修正）已经推到 GitHub，我核对过文件是完整的。但推上去 40 多分钟，网站还是旧版：服务器每 5 分钟自动拉一次，这次没拉成。我登不进服务器，要你看一眼。

**这些命令只是看状态、补拉一次，不会删东西，不会让网站停。**

## 操作步骤（宝塔终端）

**① 打开宝塔终端**：左侧菜单最下面的「终端」。

**② 粘贴这一段，回车：**

```bash
tail -15 /var/log/cantonlock-deploy.log; df -h /www | tail -1; cd /www/wwwroot/cantonlock.com && git log -1 --oneline
```

**截图整屏发我。** 我要看三样：最后几行日志（有没有 `fetch failed` 或 `reset failed`）、磁盘还剩多少、服务器现在停在哪个版本。

**③ 手动补拉一次，粘贴这一行，回车：**

```bash
flock -w 600 /tmp/cantonlock-deploy.lock /usr/local/bin/cantonlock-deploy.sh; echo "exit $?"; git -C /www/wwwroot/cantonlock.com log -1 --oneline
```

这次改了 4.8 万个文件，**可能要等几分钟**，屏幕没动静是正常的，别关窗口。

**成功的样子**：出现一行 `updated to ……`，最后是 `exit 0`，再下一行的版本号和 ② 里的不一样（变新了）。

**不成功**（看到 `fetch failed`、`reset failed`、`exit 1`，或者等了 10 分钟还没反应）：整屏截图发我，**不要自己再试别的命令**。

**④ 成功以后去 Cloudflare purge。**
