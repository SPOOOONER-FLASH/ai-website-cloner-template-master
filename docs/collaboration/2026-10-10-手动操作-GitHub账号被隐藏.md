# GitHub 账号被隐藏：先让网站恢复更新，再申诉（2026-10-10）

**现象**：服务器每 5 分钟拉一次代码，从 10-10 18:50（服务器时间）开始全部失败，日志写的是 `could not read Username for 'https://github.com'`。网站一直停在下午的版本。

**原因（已实测）**：GitHub 账号 SPOOOONER-FLASH 对外隐藏了。用无痕窗口打开 `github.com/SPOOOONER-FLASH` 是 404，账号下所有公开仓库也都是 404。你登录以后看一切正常，所以仓库设置里还显示 Public。服务器拉代码时没有登录，就拉不到。

两件事都要做：第一部分大约 10 分钟，第二部分大约 5 分钟。

## 第一部分：给服务器配一把只读钥匙（网站马上能更新）

在宝塔面板的「终端」里操作，和上次截图是同一个地方。

**1. 生成钥匙**，一次粘贴下面两行：

```bash
ssh-keygen -t ed25519 -f /root/.ssh/cantonlock_deploy -N "" -C "cantonlock-server"
cat /root/.ssh/cantonlock_deploy.pub
```

成功的话，最后一行以 `ssh-ed25519 AAAA` 开头，以 `cantonlock-server` 结尾。把这一整行复制下来。

**2. 把钥匙加到 GitHub**（在电脑浏览器上，已登录状态）：

1. 打开 `https://github.com/SPOOOONER-FLASH/ai-website-cloner-template-master/settings/keys`
2. 点绿色按钮 **Add deploy key**。
3. Title 填 `cantonlock server`；Key 粘贴第 1 步复制的那一行。
4. **不要勾选** Allow write access，服务器只需要读。
5. 点 **Add key**。如果要求输入密码或验证码，照常输入。

**3. 让服务器用这把钥匙。** 先看服务器上有没有旧的 SSH 设置：

```bash
cat /root/.ssh/config
```

- 显示 `No such file or directory`，或者内容里没有 `github.com`：继续下一步。
- 内容里**已经有** `github.com`：**停在这里，截图发给 Claude**，不要往下做。

```bash
printf 'Host github.com\n  HostName ssh.github.com\n  Port 443\n  User git\n  IdentityFile /root/.ssh/cantonlock_deploy\n  IdentitiesOnly yes\n' >> /root/.ssh/config
chmod 600 /root/.ssh/config
ssh -T git@github.com
```

第一次会问 `Are you sure you want to continue connecting (yes/no)?`，输入 `yes` 回车。

成功的样子：`Hi SPOOOONER-FLASH/ai-website-cloner-template-master! You've successfully authenticated, but GitHub does not provide shell access.`

如果看到 `Permission denied`，或者一直卡住不动：**停在这里，截图发给 Claude**。

**4. 把拉取地址改成钥匙方式**：

```bash
cd /www/wwwroot/cantonlock.com
git remote set-url origin git@github.com:SPOOOONER-FLASH/ai-website-cloner-template-master.git
git remote -v
```

成功的话会显示两行，都以 `git@github.com:SPOOOONER-FLASH/...` 开头。

**5. 立刻部署一次**，不用等 5 分钟：

```bash
flock -w 600 /tmp/cantonlock-deploy.lock /usr/local/bin/cantonlock-deploy.sh; tail -3 /var/log/cantonlock-deploy.log; git log -1 --oneline
```

成功的话，最后一行的版本号不再是 `e01d2e8d1d7`，而是更新的号码。这条命令可能要等一两分钟，期间屏幕没有输出是正常的。

做完截图发给 Claude，我去线上核对。

## 第二部分：向 GitHub 申诉，解除隐藏

钥匙只解决服务器拉代码，账号对外仍然看不见。买家和搜索引擎看不到这个仓库没关系，但账号被标记，以后可能会有更多限制，所以要申诉。

1. 登录 GitHub，打开 `https://support.github.com/contact`
2. 选和账号相关的选项，比如 *Account* 或 *My account is flagged / restricted*。
3. 把下面这段英文粘进去：

> Hello, my account SPOOOONER-FLASH appears to be hidden from the public since 10 October 2026: my profile and all my public repositories return 404 when logged out, while I can still use them when logged in. I use the account to publish the website of my company (a door-hardware manufacturer); the repository ai-website-cloner-template-master holds the site's source and its static build, which is why it receives frequent, large commits. Could you please review the account and restore its public visibility? Thank you.

4. 提交。GitHub 一般几小时到几天回复，回复会发到你的注册邮箱。
