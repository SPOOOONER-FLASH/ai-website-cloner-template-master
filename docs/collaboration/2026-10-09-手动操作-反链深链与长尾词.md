## 第一件：把目录网站上的帖子改链到对应产品页（最省事、马上见效）

这三个目录网站上的帖子是我们自己发的，链接你能改。我按帖子网址里的型号逐条对好了：**139 条里有 69 条能改成产品页**（worldbid 51、traderscity 15、etradeasia 3），对照表在桌面 `hyde\BACKLINK-DEEPLINKS.docx`。

1. 登录 worldbid.com（先做它，51 条最多）→ 我的产品 / My Products。
2. 打开对照表，按「帖子」一列找到那条产品帖 → 编辑。
3. 把帖子里的网站链接 `https://www.cantonlock.com/` 换成对照表「把网址改成」那一列的地址。
4. 如果帖子正文能写文字，链接前写上型号和品名，例如 `LC8525 PS mortise lock case`，不要只放网址。
5. 保存后点开帖子，点那个链接，**成功的样子**：直接打开我们网站那个型号的产品页。
6. traderscity、etradeasia 同样做。对照表写着「对不上，保持首页」的不用动。

做不完没关系，先做 worldbid 的 51 条。改链不会删掉原有的链接，只是让它指向更对的页面。

## 第二件：GSC 导出五个页面各自的搜索词（约 10 分钟）

10-09 那份导出能看到「有哪些长尾词」，但看不到**每个词落在哪一页**，所以改哪一页只能推断。五个曝光最多的页面各导一次，就能逐页按词改。

1. https://search.google.com/search-console → cantonlock.com → **效果** → **搜索结果**。
2. 顶部 **+ 新建** → **网页** → **网址包含** → 粘贴下面一个地址 → 应用。
3. 日期选 **过去 3 个月** → 右上角 **导出** → **下载 CSV**。
4. 清掉网页筛选，换下一个地址，重复。

## 不建议做的

- 买链接、批量提交几百个目录、在论坛留言贴网址：Google 会把这类链接整体打折，严重时整站降权。
- 付费 Semrush / Ahrefs：之前说过，不值。Ahrefs Webmaster Tools 免费版照常开（10-08 那份 Word 第 ③ 节）。
