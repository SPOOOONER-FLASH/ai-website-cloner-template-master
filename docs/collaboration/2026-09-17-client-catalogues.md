## 合页目录的版式 —— 和《雷茵五金》完全不同，不能套凯撒那套脚本

每个跨页 = 两个 A4 纵向面板，每个面板 3 行，一行是

    照片   |   型号代号 + 中英双语规格块   |   尺寸图

**规格块本来就是双语的**（Material / Finish / Features / Available For），
不用猜翻译 —— 这一点比《雷茵五金》那本省事。没有表面处理色样网格。

三列的边界是量出来的：照片 0.135–0.307、文字 0.420–0.640、图纸 0.745–0.858
（占面板宽）。第一版把图纸窗口从 0.62 起写死，把文字列的右半截裁进了图里 ——
中文烤进图片，英文站就翻不了。现在每行自己分列，取第一段作照片、最后一段作图纸。

### ⚠ 这本书是「同一个型号按材质和表面分格排」，不是一格一个型号

**这是最容易上错的地方，差点写出 124 条重复记录。**

裁出来 124 个产品格。但 p08 四格的代号一模一样，都是 `4x3x3.0-4BB`，
区别只在 表面处理：亚光青古铜 MAB / 亚光红古铜 MAC / 枪灰色 HH / 亚光黄古铜 YAC ——
而这个代号在 p02 已经以 砂光 SS 出现过。p12、p16 再来一遍，材质换成 **纯铜**。

去重之后是 **约 50 个型号**，每个带：

* **材质**：不锈钢 (304/201) 或 纯铜 —— 同代号两种材质都有，slug 必须区分
* **表面**：SS 砂光、MAB 亚光青古铜、MAC 亚光红古铜、HH 枪灰色（纯铜版叫银河灰）、
  YAC 亚光黄古铜、SB 磨砂铜、FGT 法国古铜、ORB 黑黄古

注意 HH 在不锈钢页写「枪灰色」、在纯铜页写「银河灰」。按各自那一页的原文记，
不要统一 —— 那是工厂自己的叫法。

p10、p11、p21 是表面展示页和色卡，没有规格块，不是产品。

### 代号就是尺寸，可以验算

`4x3x3.0-4BB` = 4″ × 3″ × 3.0mm、4 颗轴承。4″ = 101.6mm、3″ = 76.2mm，
和图纸上印的 101.6 / 76.2 / 3.0 对得上 —— 这几个数是**算出来再和图纸核对**的，
不是抄的。轴筒直径 φ14.2 这类只在图上有，得逐张读。

也有直接用毫米的：`100x89x3.0-1BB`、`110x55x2.5-1BB`、`140x55x2.5-1BB`。

后缀分：圆角、美标、双钉防盗合页、单钉防盗合页、中轴、偏轴、拉手、焊头。
轴承位分 0BB / 1BB / 2BB / 4BB / 6BB / 2DD。

### 上架前要定的一件事

同一个代号在不锈钢和纯铜下是两个产品，slug 会撞。倾向
`4x3x3-0-4bb-stainless-hinge` / `4x3x3-0-4bb-brass-hinge` 这样分，
类目进现成的 `brass-steel-hinges`（铜与钢门合页）—— 名字正好覆盖两种材质。

## 《雷茵-铰链和门吸》：名字里的「铰链」是液压铰链，不是平开合页

一本书装了两本，两种版式：

* **p1–p24 液压铰链**，六个型号。RY8001/8002/8003/8004 是三维暗藏液压铰链
  （分别是标准、大距边、窄边、免开槽四支），RY8005/8006 是 5 寸和 6 寸液压合页。
  每个型号占好几个跨页做编辑内容，规格集中在其中一页的**彩底面板**上：
  左上规格表、左下尺寸图、右边 2×3 的表面处理图。
* **p25–p37 门吸**，十二个型号（273-1、273、275、271、272、270、280、220、274、
  1328、209、215），白底面板，版式完全一致：左上型号 + 小规格块 + 「可选表面处理」色块清单，
  下面一张小尺寸图，右边一格一格的表面处理照片，对页一整幅实景图。

两个类目都是现成的：液压铰链进 `floor-springs-and-pivots/hydraulic-hinges`
（原来只有 JL606–609 四个），门吸进 `hardware-accessories/door-stoppers`（原来七个 DS）。
不用新开类目，也就不会在 HYDE、Stahlock 上产生空类目页。

### 和前几本不一样的三件事

1. **这本全中文**，不像暗铰链那本是中英双语的。英文是照中文写的，中文回站上由
   `zh-terms.json` 的 specLabels / phrases 还原成图册原话 —— 这一轮加了
   21 条规格标签、13 个词、52 条整句。
2. **液压铰链的尺寸图是白线画在近黑底上**，裁完做了反相 + 灰阶拉伸，变成和站上其它尺寸图
   一样的黑线白底。线稿反相只换极性；照片一张没反。
3. **门吸的对页是整幅实景图**，收进来作每个型号的最后一张。窗口是「页宽见方、贴页面底边」。
   273 例外 —— 它那张左下角印着「门缝不低于5mm／门缝不大于15mm」，中文烤进图里英文站翻不了。
