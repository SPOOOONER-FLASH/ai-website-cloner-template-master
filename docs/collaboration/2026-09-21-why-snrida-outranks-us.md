## 一、你对视觉的判断是对的，而它和排名无关

那个 F5600 页面的产品图上印着 **`TENGLONG CATALOG`** —— 一本第三方目录的名字。
甲方的判断（「那上面这些图片都是抄的东冠的，拿的型号也是东冠的」）和页面上
自己印的标一致。

**但引擎不看这个。** AI 引用是从**文字**里抽事实，不是从版式或图片质量里。
我们把 UX 做得比他们好，在这件事上换不到一条引用。

## 三、最要紧的一条：**他们那些内容一条都不需要工厂给数据**

逐条看他们赢在哪：

| 文章 | 数据来自哪里 |
|---|---|
| Door HS Code Complete Guide | 各国海关税则，公开 |
| NFPA 80 Clearance Rules | 规范文本，公开 |
| EN 1154 & ANSI/BHMA A156.4 闭门器 | 标准文本，公开 |
| RAL Colors / 粉末涂装 | 色卡，公开 |
| Container Loading 20GP/40GP/40HQ | 箱型内尺寸 ÷ 门扇尺寸，算术 |
| STC 声学等级 | 标准定义，公开 |
| 304 vs 316 vs 201 | 材料牌号，公开 |

**我们被工厂卡住的是产品页的尺寸，不是这一类内容。**
而我们一直把"等工厂"当成内容产出的瓶颈 —— 对产品页成立，对这一类不成立。

这是这份文档里唯一真正的发现：**我们为一类根本不需要工厂数据的内容，
等了工厂两个星期。**

## 四、能抄什么，不能抄什么

### ✅ 能抄，而且应该抄

1. **公共数据的查表文章。** HS code、集装箱装载量、RAL 色号、EN/ANSI 对照、
   NFPA 间隙 —— 全是公开事实，写出来是整理不是编造。
2. **标题里放年份和规范号。** 我们 35 篇里标题含年份的是 **0**。
3. **FAQ 从 3 问加到 6 问。** 问答块是被引用密度最高的文字形式 ——
   一个问答直接对应一个提问。
4. **篇幅。** 730 字对 2,300 字。不是灌水 —— 是我们每篇只回答一个问题，
   而他们把一个主题的相邻问题一次答完。

### ❌ 不能抄，而且要写下来为什么

**他们的产品页规格是从别人的目录里拿的。** `TENGLONG CATALOG` 印在图上，
F5600 那一页的 "UL 10C listed up to 3 hours"、"ANSI/BHMA A156.3-2008 Grade 1"、
"Over 500,000 cycles" 全部是这么来的。

`AGENTS.md` 第三条规矩：**不借用别人的资质、场地、商标。** 这个仓库为此
清理过 660 张烧着 Hyland 标的图和一批 UNION 厂标。

而且这对我们是**风险**不是机会：UL 列名和 BHMA 目录都是公开可查的，
规格制定者要把证号写进送审文件。一个抄来的证号被查一次，
这家供应商的所有数字都作废。**我们 307/311 的证书还在送检，
在证号下来之前任何材料都不得暗示我们已持有 ANSI 或 UL。**
