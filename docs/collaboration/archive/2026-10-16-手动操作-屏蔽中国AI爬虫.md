# cantonlock.com 屏蔽中国 IP 和中国 AI 爬虫（2026-10-16）

你的要求：「防止中国 AI 爬取，不让中国公司偷取我的架构和成果，不允许中国 IP 分析拆解 SEO / GEO / SXO / AEO / AIO」。

一共三道防线。前两道我已经写进代码，第三道要你在 Cloudflare 里点，大约 10 分钟。

| 防线 | 拦什么 | 谁来做 | 状态 |
|---|---|---|---|
| 1. robots.txt | 告诉百度、字节、阿里神马、搜狗、360、华为、智谱的爬虫「整站不许抓」 | 我（代码） | 已写好，下次 HYDE 发布后生效 |
| 2. 服务器 nginx | 上面这些爬虫和 Python、Scrapy、Go 等批量抓取工具，直接返回 403 | 我写好，你在服务器跑一条命令 | 等合并发布后执行，见第 2 步 |
| 3. Cloudflare 防火墙 | **所有中国大陆 IP**，以及上面这些爬虫 | 你 | 见第 1 步，**这是最关键的一道** |

为什么 Cloudflare 那道最关键：robots.txt 只是「请求」，字节的 Bytespider 出了名不遵守；nginx 只拦得住到达服务器的请求，而 Cloudflare 缓存住的页面根本不经过服务器。只有在 Cloudflare 这一层拦，才是全拦。

**不受影响的：** Google、Bing，以及 ChatGPT、Claude、Perplexity、Gemini 的爬虫照常抓取。海外买家就是通过它们找到我们的，GEO 的成果靠的就是它们，所以一个都不拦。雷茵（rayen.cn）完全不受影响。

## 第 1 步：Cloudflare 加一条防火墙规则（现在就可以做）

1. 登录 Cloudflare，点进 **cantonlock.com**。
2. 左侧菜单点 **Security（安全性）**，再点 **Security rules（安全规则）**。旧版界面是 **WAF → Custom rules（自定义规则）**。
3. 点 **Create rule（创建规则）**。如果让你选类型，选 **Custom rule（自定义规则）**。
4. **Rule name（规则名称）** 填：`Block CN and CN crawlers`
5. 点右侧 **Edit expression（编辑表达式）**，把下面整段**原样**粘进去：

```
(ip.src.country eq "CN") or (lower(http.user_agent) contains "bytespider") or (lower(http.user_agent) contains "tiktokspider") or (lower(http.user_agent) contains "baiduspider") or (lower(http.user_agent) contains "yisouspider") or (lower(http.user_agent) contains "sogou") or (lower(http.user_agent) contains "360spider") or (lower(http.user_agent) contains "haosouspider") or (lower(http.user_agent) contains "petalbot") or (lower(http.user_agent) contains "chatglm-spider")
```

6. **Then take action（选择操作）** 选 **Block（阻止）**。
7. 点 **Deploy（部署）**。

**成功的样子：** 规则列表里出现 `Block CN and CN crawlers`，状态是开启（Enabled）。几分钟后，规则旁边会开始显示被拦截的次数。

**如果点 Deploy 报错（expression 红字）：** 把表达式最前面的 `ip.src.country` 改成 `ip.geoip.country`，再点 Deploy。还报错就截图发我，**不要改别的地方**。

### 公司在国内的同事怎么办（务必看）

规则生效后，**在中国大陆不开 VPN，就打不开 cantonlock.com**，包括后台 `/admin/`（产品编辑）。只会看到 Cloudflare 的拦截页。两个办法，二选一：

- **办法 A（最简单）：** 国内同事看官网、改后台都开 VPN（节点选香港、新加坡或美国）。
- **办法 B：** 公司宽带如果是**固定 IP**，可以给它放行。先在公司电脑上打开 `https://ip.sb`，记下显示的 IP（例如 `113.66.12.34`）。然后把第 5 步表达式的开头 `(ip.src.country eq "CN")` 改成：

  ```
  (ip.src.country eq "CN" and not ip.src in {113.66.12.34})
  ```

  有多个 IP 就用空格隔开：`{113.66.12.34 14.23.45.67}`。家用宽带的 IP 经常会变，不适合用这个办法，还是开 VPN。

### 同时检查一个开关，**一定不要打开它**

Cloudflare 有一个一键「屏蔽 AI 爬虫」的开关，入口在 **AI Crawl Control** 或 **Security → Bots** 里，叫 *Block AI bots* 或 *AI Scrapers and Crawlers*。**它会把 ChatGPT、Claude、Perplexity 的爬虫一起拦掉**，我们的 GEO 等于白做，海外买家问 AI 时就不会再看到我们。

- 如果这个开关是开着的，把它关掉。
- 如果是按爬虫逐个设置的界面，确保 GPTBot、OAI-SearchBot、ChatGPT-User、ClaudeBot、Claude-SearchBot、PerplexityBot、Google-Extended 都是 **Allow（允许）**。Bytespider 可以设成 **Block（阻止）**。

## 实话：哪些挡得住，哪些挡不住

**挡得住的：**
- 中国大陆 IP 的人工访问，以及 SEO 工具直接从大陆发起的抓取。
- 字节（豆包）、百度（文心）、阿里（通义 / 夸克）、搜狗、360、华为、智谱这些公司的已知爬虫，**无论它们从哪个国家的服务器发起**。Cloudflare 规则和 nginx 都是按爬虫名字拦的，不看 IP。
- 用 Python、Scrapy、Go 写的批量抓取脚本（nginx 那道）。

**挡不住的：**
- **开 VPN 或用海外服务器、又伪装成普通浏览器的人。** 在网站眼里，他和一个德国买家没有区别。任何能给买家看的东西，就能被他看到。
- **页面本身的结构：** 标题、Schema 标记、llms.txt、网站用了什么框架。这些必须公开给 Google 和 AI 看，否则 SEO 和 GEO 就不存在了。

所以真正的护城河不是「藏」，而是**他们抄不走的东西**：工厂实拍图、真实尺寸和规格、几百款产品的规格数据、十种语言的持续更新速度。抄走一份快照的人，追不上每周都在更新的我们。

## 以后可以再加的（需要时告诉我）

- **只允许 Cloudflare 访问服务器：** 如果有人知道服务器的真实 IP，可以绕过 Cloudflare 直接访问。可以让服务器只接受 Cloudflare 转发的请求。这一步改错了会让整站打不开，要单独、小心地做。
- **香港：** 规则目前只拦中国大陆（CN），香港（HK）、台湾、澳门是 Cloudflare 里单独的地区，没有拦，因为香港有不少真实的贸易商和买家。要拦的话，把表达式开头改成 `(ip.src.country in {"CN" "HK"})`。
