## 第一步：建一个 Google 服务账号（GSC 和 GA4 共用，约 10 分钟）

1. 打开 https://console.cloud.google.com/ ，用管理 GSC 的那个 Google 账号登录。
2. 顶部点项目下拉框 → **新建项目**，名字写 `hyde-analytics`，点创建。
3. 左上角菜单 → **API 和服务** → **库**，分别搜索并点**启用**：
   - `Google Search Console API`
   - `Google Analytics Data API`
4. 左上角菜单 → **IAM 和管理** → **服务账号** → **创建服务账号**：
   - 名称写 `hyde-reader`，点**创建并继续**，角色不用选，点**完成**。
5. 点进刚建的服务账号 → **密钥** → **添加密钥** → **创建新密钥** → 选 **JSON** → 创建。浏览器会下载一个 `.json` 文件。
6. 在 E 盘新建文件夹 `E:\hyde-keys\`，把这个文件放进去（不要放进网站代码文件夹，也不要发到聊天里），告诉我文件名。

**成功的样子：** 第 4 步完成后，服务账号列表里出现一个邮箱，形如 `hyde-reader@hyde-analytics.iam.gserviceaccount.com`。**记下这个邮箱**，第二、三步要用。

**没成功：** 如果第 3 步找不到「启用」按钮，或第 5 步提示「组织政策禁止创建密钥」，截图发我。

## 第二步：GSC 给服务账号只读权限（约 2 分钟）

1. 打开 https://search.google.com/search-console ，选 cantonlock.com 资源。
2. 左下 **设置** → **用户和权限** → **添加用户**。
3. 邮箱填第一步记下的服务账号邮箱，权限选 **受限**（只读就够），点添加。

**成功的样子：** 用户列表里出现这个邮箱，权限「受限」。

## 第三步：GA4 给服务账号只读权限，并告诉我媒体资源 ID（约 3 分钟）

1. 打开 https://analytics.google.com/ ，选账号「hyde数据看板」、媒体资源 cantonlock。
2. 左下齿轮 **管理** → 媒体资源一栏 → **媒体资源访问权限管理** → 右上 **+** → **添加用户**。
3. 邮箱填服务账号邮箱，角色选 **查看者**，点添加。
4. 还在 **管理** 页，点 **媒体资源设置**（或「媒体资源详情」），右上角有一串**纯数字的媒体资源 ID**（例如 `412345678`）。**把这串数字发我。**

**注意：** `G-RBTE7KF82P` 是衡量 ID，不是媒体资源 ID，API 用的是那串纯数字。

## 第四步：Clarity 生成 API 令牌（约 2 分钟）

1. 打开 https://clarity.microsoft.com/ ，进项目 hyde。
2. **设置**（齿轮）→ **数据导出**（Data Export）→ **生成新的 API 令牌**。
3. 名字写 `hyde-weekly`，生成后复制那一长串令牌，发我。

**Clarity 的限制（官方规定）：**

- 每次只能拉最近 1–3 天的数据；
- 每个项目每天最多 10 次。

所以 Clarity 要每 3 天拉一次才不断档。接好后我设成自动拉。
