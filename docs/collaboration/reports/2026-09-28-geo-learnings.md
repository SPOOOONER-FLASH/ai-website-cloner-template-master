# GEO 学习与进展（2026-09-28）

文案会话（Hyde 文案）。甲方转来 QuickCreator 的 GEO 系列与 SEO 文章约二十篇，本文件说明：学到了什么、据此做了什么、完成到哪一步、要你做什么。
桌面版由 `node scripts/build-geo-report.mjs` 生成，别直接改 Word。

## 一、学到了什么（只留和我们有关的）

| 文章的判断 | 对 HYDE 意味着什么 |
|---|---|
| 测 AI 要用**零品牌词**：问题里不提任何品牌，看 AI 自己点谁 | 我们从没测过。先建题库、摸底，以后每季度同一套题复测 |
| **被提到 ≠ 被推荐**；四个 AI 平台推荐结果各不相同 | 记录时分开记“列出”和“点名推荐”，四个平台分开记 |
| AI 读的是**引用图谱**：第三方评测、行业媒体、LinkedIn、YouTube；广告和通稿几乎不起作用（通讯社稿只占 AI 引用 0.04%） | 站外要补：LinkedIn 公司主页（没有）、YouTube（有频道）、行业目录深链（清单已有，待甲方） |
| AI 最常引用**具体、先给答案**的内容；页面前 30% 拿走约 44% 引用，结尾几乎不被引用 | 82 篇文章里 46 篇前两段没有任何数字或标准号，开头多是叙事钩子 |
| **一个常青页回答多个问题**，胜过十个单问题薄页；1,000 字以下的薄页各行业都不行 | 我们的指南都是长文、一页多问，方向对；薄的是 112 个没有规格的产品页 |
| **实体一致性**：官网、LinkedIn、展会、目录上公司名和事实要一模一样 | 我们有三个英文公司名在流通（官网 / 展位 / 付款） |
| **任务思维 + 机器可读**：AI 代理会替买家比参数、发询价；参数埋在图片和 PDF 里等于没有 | 已在做：规格表是 HTML、锁芯计算器、询价要提供什么 |
| **B2B 网站三问**：你可信吗、懂我的问题吗、值得联系吗；案例要放在产品页旁边 | 产品页已链应用案例（工程会话 09-27）；公司页已补“适合谁” |
| GSC“已抓取未收录”是内容问题，反复点“请求编入索引”没用 | 请甲方导出两张未收录清单，按页改内容或加内链 |
| 训练截止线：定位类内容要**早发、持续发**，才会进模型记忆 | BAU 前把公司定位、品类指南在官网和 LinkedIn 都稳定下来 |

有几条我们**不照做**：文章里“内容越长越好”“实体密度每千字 15 个”这类数字来自 SaaS 和媒体样本，五金工厂照搬会写出堆砌的文字；“AI 批量生成内容”与我们“不编造”的规矩冲突，不做。
