# 2026-10-12 手动操作：服务器硬盘清理（第 1 步：只看不删）

服务器硬盘 60G 只剩约 6G。最大的两块：

| 位置 | 大小 | 是什么 |
|---|---|---|
| `/www/wwwroot/cantonlock.com/.git` | 9.7G | 旧的 GitHub 历史。改从 GitLab 拉之后基本用不上了，可以清掉大部分 |
| `/www/server/panel` | 9.5G | 宝塔面板自己的日志和备份，要先看清是哪些文件 |
| `/.Recycle_bin` | 2.6G | 宝塔回收站 |

**这一步只查看，不删除任何东西。** 删除放在第 2 步，等我看过结果再给你。

## 操作

1. 打开宝塔 → 终端。
2. 粘贴下面这一整行，按回车：

```bash
df -h /; du -sh /www/wwwroot/cantonlock.com/.git/objects/pack; ls -lhS /www/wwwroot/cantonlock.com/.git/objects/pack/*.pack | head -8; du -xh --max-depth=2 /www/server/panel 2>/dev/null | sort -h | tail -8; ls /.Recycle_bin | head -15
```

3. 等它跑完（一般不到 1 分钟），**用截图工具截图**发给我。不要用鼠标拖选文字去复制：宝塔终端选中就会复制，一粘贴就会被当成命令执行。

## 成功的样子

屏幕上会出现 5 段输出：硬盘剩余空间、`.git` 打包文件的大小和清单、面板目录里最大的几项、回收站里的文件名。

## 不对的时候

出现 `No such file or directory`，说明那一项不存在。照样截图给我就行，其余几段仍然有用。
