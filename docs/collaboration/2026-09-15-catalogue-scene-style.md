# 凯理 / 雷茵那种产品图：拆开看它到底是怎么拍的

甲方 2026-09-15 圈了三张图（雷茵五金.pdf），并给了凯理 2025 产品图册（108 页）作为参考，
要求「理解学习这个风格，拆分分析给 Codex 精准生成这种产品图」。

这份文档是**场景与布光的规格书**，不是一份可以照着生成五金件的许可。先把这条说清楚，
因为它决定了下面每一条怎么用。

---

## 零、先说边界：这份文档允许什么、不允许什么

| | |
|---|---|
| ✅ 允许 | 按下面的配方**布置场景**：底座、背景、光、色调、机位、构图 |
| ✅ 允许 | 场景里的五金是**我们自己产品的真实照片**，抠出来合成进去 |
| ✅ 允许 | 场景里的五金是 **Blender 按公布尺寸建的几何**，并附「哪些没建」的清单 |
| ❌ 不允许 | 让模型**生成一个五金件** —— 任何风格、任何用途 |
| ❌ 不允许 | 复制凯理的具体画面、版式或文案。风格学得来，别人的图不能拿 |

**为什么这条在最前面。** `AGENTS.md` 那条规矩不是质量门槛而是类目规则：孔位、螺纹、方轴、
背距是开模之前就定死的，生成出来的执手是**装不上去的零件**，而买这些东西的人手里摸过成千
上万个。甲方的老板亲自一眼否过一批生成图。

这份文档描述的是**摄影语言** —— 光、石头、阴影、机位。那部分学过来是正当的，
而且正是它撑起了整个观感。**五金本身必须是真的。**

## 一、圈出来的三张，分别是三种场景

### A. 「石板 + 灰墙」（凯理 048 页、雷茵凯撒系列那张）

最典型的一张，也是最值得先做的。

```
背景    浅灰白无缝纸/抹灰墙，右侧一块略深的竖向色块，形成柔和的明暗台阶
底座    深灰大理石板，带白色石筋，斜置，左低右高
主体    同一个型号的两个表面 —— 一只深色（哑黑）立着靠墙，一只浅色（拉丝不锈钢）躺在板上
光      左上单一大柔光源，影子朝右下拉长、边缘柔、没有硬边
色       近乎单色，冷调；画面里唯一的「颜色」是金属本身
机位    略高于物体，轻微透视，约 50–85mm 等效，全景深
留白    上方留大片空给标志
```

### B. 「布面静物」（雷茵凯撒系列第三张）

```
背景    米色/奶油色垂坠织物，褶皱朝画面左上收拢
道具    一块浅豆绿色圆盘、一颗浅灰石球 —— 只有几何体，没有具象物
主体    三到四只同款不同表面的执手，散置，朝向各异
光      顶部偏左的柔光，织物褶皱负责把光「揉开」
色      暖中性，饱和度极低；豆绿是唯一一点非中性色，且面积很小
```

### C. 「装在门上的近景」（凯理 007 页）

```
背景    整扇浅灰抹灰质感门扇，画面只给一小段
主体    执手装在门上，占画面右侧约三分之一
光      侧光掠过门面，把抹灰质感拉出来
用途    这一张回答的不是「它长什么样」而是「它装上去是什么样」
```

## 二、真正起作用的那一件事：两个表面同框

三张图全都在做同一件事 —— **同一个形状，两个表面，放在一起。**

深的那只吃光，浅的那只反光；一只立、一只躺。这一个动作同时做到三件事：

1. **它证明了一致性。** 两只除了颜色完全一样 —— 这正是「这家工厂有工艺流程」的视觉证据，
   也正是 `AGENTS.md` 里那条「Consistency IS the argument」
2. **它把表面变成可以比较的东西。** 单独一只哑黑执手你不知道它有多黑；旁边放一只拉丝的，
   两个都读得出来了
3. **它不需要任何文案。** 一个买家看一眼就知道这个型号有几种表面

**我们做得了。** 全目录里 **68 个型号组**有两个及以上同形状不同表面的变体
（`70` 系锁芯 19 个、`587` 8 个、`607` 7 个、`D101` 6 个、`LH853` 5 个……），
每一个都已经有真实照片。**这批图不需要工厂补拍任何东西。**

## 三、执行：在这个仓库里怎么做

### 路线一（优先）：真实照片合成

我们有 4,055 张打过标的产品图，其中大量是白底抠图 —— 那是合成的理想素材。

```
1. 从 public/images/products/ 取同一型号两个表面的白底图（未打标的根目录）
2. 抠图 → 放进按上面配方搭的场景
3. 按真实相对尺度摆放（AGENTS.md：composing real photographs at true relative scale）
4. 阴影要和场景的光向一致 —— 这是唯一容易穿帮的地方
5. 出图后过 npm run assets:watermark 或编辑图打标流程
```

⚠ **不要混表面。** 一个画面里出现黑色执手配铬色罗斯，就是在展示一个我们不卖的东西。
`AGENTS.md` 写着：客户订黑色，画面里每一件都是黑色。**A 场景的「两个表面同框」是例外，
而且必须是两件完整的产品，不是一件产品的两半。**

### 路线二：Blender 几何

Codex 已经有这条管线（9004S / LC04 / 70SN）。配合
`docs/collaboration/2026-09-15-modelling-shortlist.md`：

**管状拉手 100 / 102 / 104 / 106 / 107 是目前唯一可以建完整模型的一批** ——
外径、壁厚、总长、中心距、离面距五个数全部公布，没有一处需要假设。
它们放进 A 场景（斜置石板）会非常好看，而且**不需要附「哪些没建」的清单**。

其余仍是局部模型，附清单，照旧。

## 四、光的配方（这部分是可以直接照抄的）

```
主光    大柔光箱，画面左上约 40°，距离约等于主体长度的 2–3 倍
        → 影子长度约为主体高度的 1.5–2 倍，边缘柔到几乎看不见转折
补光    右侧一块白卡，强度约主光的 1/8
        → 只把暗面从死黑提到能看见倒角，不制造第二道影子
背景光  无。背景的明暗台阶靠主光的自然衰减，不靠第二盏灯
反射    金属上不应出现可辨认的环境倒影 —— 柔光箱要大到在金属上形成一条连续的长高光
```

**最容易做错的一条**：影子太硬、或者有两道影子。那一眼就从「产品摄影」掉到「合成图」。

## 五、色与质感

| 元素 | 取值 |
|---|---|
| 背景 | L\* 88–92 的中性浅灰，**不是纯白**。纯白会让金属的浅色表面消失 |
| 石板 | 深灰带白筋。石筋走向要斜，和板的斜置方向大致一致 |
| 织物 | 米色到奶油，L\* 75–82 |
| 点缀色 | 至多一处，低饱和（豆绿、灰蓝），面积不超过画面 5% |
| 金属 | 唯一允许有「颜色」的东西 |

**整个画面的饱和度预算极低。** 凯理那本册子 108 页里几乎没有一处纯色 —— 这不是审美偏好，
是让金属成为画面里唯一被注意的东西。

## 六、构图

- **对角线。** 石板边缘、织物褶皱、躺着那只执手的轴线 —— 三者里至少两条走对角
- **一立一躺。** 立着的那只制造高度和影子，躺着的那只交代形状
- **上方留白。** 凯理每一张右页的顶部都留出标志的位置。我们的标放左上（和产品图打标一致）
- **不要居中。** 主体重心在画面右侧或右下，左上是空的

---

## 七、出图前的检查表

- [ ] 画面里每一件五金都是**真实照片或有公布尺寸支撑的几何**
- [ ] 同一画面内表面一致（A 场景的两表面对照除外，且两件都是完整产品）
- [ ] 只有一道影子，方向与主光一致
- [ ] 金属上没有可辨认的环境倒影
- [ ] 没有可读文字、没有伪造的认证标、没有别家的商标
- [ ] 相对尺度真实（执手和罗斯的比例、石板厚度和执手的比例）
- [ ] **那个问题**：买家能不能拿着这张图去车间订这个零件？要加限定语就不发
