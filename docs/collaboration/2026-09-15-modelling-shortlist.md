# 还能建什么模型 — 给甲方与 Codex 的清单

2026-09-15。两个审计脚本，跑一次就重新生成，不要手抄这份文件里的数字：

```bash
npm run audit:modelling           # 全目录：公布尺寸能不能确定外形
npm run audit:modelling:alibaba   # 交叉阿里 43 个产品的九十天真实询盘
```

---

## 判据：不是「有几行规格」，是「公布的尺寸有没有确定整个外形」

已上线那三份（9004S 外形、LC04 包络、70SN 上壳）都是**局部**模型，每份都附了一张
「哪些没建」的清单 —— 因为公布的数据在形状用完之前就用完了。LC04 的说明文件自己写着
15mm 厚度是「假设的闭合值，不是公布的产品尺寸」。

那是诚实发布局部模型的方式，同时也是一句警告：**这个目录里大部分东西建不了模**，
因为大部分是没有人公布过的曲面。

所以审计不按规格行数排。有九行规格的执手仍然是一条谁也确定不了的有机曲线；
有七行的锁体仍然是一个内部是机构的盒子。按行数排会把它们排在最前面，
然后生产出 `AGENTS.md` 明令禁止的那种臆造几何。

背距、锁舌行程这些是页面上最有价值的几行，但它们说的是**这把锁怎么工作**，
一个字也没说它长什么样 —— 所以判据里故意不含它们。

## 一、现在就能建，而且是完整模型不是局部：管状拉手五个

| 型号 | 已公布 |
|---|---|
| **100 / 102 / 104 / 106 / 107** | 外径、壁厚、总长、中心距、离面距 —— 五个数一个不缺 |

一根圆管拉手**就是**它的尺寸。给出这五个数，剩下没有任何东西需要猜：
没有要谁去发明的圆角，没有深度「大概对」的面，没有藏在盖板后面的内部零件。

```
102:  Ø32mm · 壁厚 1.0mm · 长 600mm · 中心距 147mm · 离面 26mm · 玻璃缝 8mm
106:  Ø32mm 渐变 18.5mm · 握持段 140mm · 中心距 125mm · 离面 26mm · 玻璃缝 7mm
```

五个是同一族、同一套图纸约定，**一个参数化生成器出五个**。106 带锥度，同样完全确定。

**与已上线那三份的区别**：这些不需要「哪些没建」的清单，因为没有没建的。

另外两个够得着的：

- **001 逃生器械面板** —— 面板尺寸 + 厚度都有，可建完整面板。面板上的执手或推杠不可建
- **LC07 85×45mm** —— 可建包络，而且**比 LC04 好**：面板、壳高、壳深三个数都公布了，
  不需要像 LC04 那样假设一个厚度

## 二、阿里那 43 个产品：只有一个现在能建，但差的东西很少

| 结论 | 数量 |
|---|---|
| COMPLETE 现在能建 | **1**（102，但它 90 天 0 询盘） |
| NEEDS DATA 差几个数 | 20 |
| NO RECORD 阿里列表没有型号号 / 目录里没有 | 17 |
| NO 形状不由尺寸决定 | 5 |

**询盘最高的五个全都只差两三个数。** 这是这份审计真正的产出 ——
「307 建不了」对谁都没用，「**307 差两个数，给了就能建**」是一个上午能答完的请求，
而 307 是店里询盘最多的型号：

```
Plate size       307 (5 询盘) · 311 (4) · 305 (3) · 035 (1) · 308 (1)
Plate thickness  307 (5)      · 311 (4) · 305 (3) · 035 (1) · 308 (1)
Faceplate        6068 (3)
Case height      6068 (3)
Case depth       6068 (3)
```

**要工厂给的就是这三类、七个型号。** 面板尺寸与面板厚度给了，五个逃生器械面板就能建；
6068 的面板、壳高、壳深给了，它就能出包络 —— 而 6068 刚刚才上线，是全表转化率最高的那个。

## 三、顺带查出来的两件，不是建模但值得处理

**阿里 17 条列表没有型号号。** 其中有 90 天 2 询盘的「Matte Black Euro-standard Door
Lock Cylinder」和 1 询盘的「Universal Blank Key」。它们在阿里有真实询盘，
**在我们站上找不到对应记录** —— 不是建模问题，是目录缺口。
`587 SS ET`、`9007 E`、`F100`、`9087`、`LH1033`、`1073 DL` 这几个号在目录里也对不上，
可能是写法差异（`587 SS ET` vs `587 SSET`），值得核一遍。

**「310+015」是一条列表两个产品**，2 询盘。此前已记过：套装起订量不能拆到两个单品页。

## 不要做的

`564`、`5836`、`SSH016`、`DC02`、`607 SSET` —— 形状不由公布尺寸决定。
差的不是几个数，是整个轮廓。给这些建模只能靠猜，而猜出来的孔位装不上去。
