# HYDE 桌面文件夹目录说明

生成：`node scripts/organize-desktop-hyde.mjs`，2026-10-19 更新。以后新出的 Word 会自动放进对应文件夹。

| 文件夹 | 放什么 | 你什么时候看 |
|---|---|---|
| 00-先看这里-人工待办 | 人工代做清单、操作手册、正在等你做的「手动操作」Word | **每次先看这里** |
| 01-待做计划 | 待做计划（工程目标里没完成的事）、旧的 TODO 总表 | 想知道还剩什么没做 |
| 02-周报与数据结论 | 周报、月度总结、数据结论、长尾词报告、审计报告 | 看结果和趋势 |
| 03-研究与方案 | 研究、方案、评估、Clarity 话题、参考图、LinkedIn 文案 | 需要背景时 |
| 04-数据库-原始导出 | GSC、Bing 等后台导出的原始数据，按导出日期一个文件夹 | 本地数据库：周环比、同比都从这里算 |
| 05-目录与报价 | 产品目录 PDF、报价单 | 发客户时 |
| 09-旧资料归档 | 9 月旧资料、做完的人工操作、旧版手册、移动记录 | 一般不用看 |

## 以后导出的数据放哪

从 Search Console、Bing 下载的文件照常发我。我存进仓库，并按日期复制到「04-数据库-原始导出\日期」，两边都有。
