# 10-19 数据结论：那几篇 SEO 帖子，哪些用得上

## 一句话结论

**每周复盘的四步我们已经做齐；工具页值得试 2 个；垃圾外链先别 disavow，先查一项。** 每日清单和 SOP 表主要是给零售站用的，和询盘型的 HYDE 关系不大。

## 1. 每周复盘四步：已经做齐，每周一自动出

| 帖子里的步骤 | 我们用什么 | 状态 |
|---|---|---|
| ① 和上周比点击、曝光 | `node scripts/build-weekly-kpis.mjs` | 已有 |
| ② 有曝光、点击少的网页 | `node scripts/build-seo-opportunities.mjs`（今天新加） | 新 |
| ③ 排第 8–20 名的搜索词 | 同上 | 新 |
| ④ 记下每周改了什么 | 上线日志（每一版都有版本号） | 已有 |

用 10-19 的 28 天数据跑了一次，发现了一个之前没看出来的问题：

| 网页 | 28 天曝光 | 点击 | 排名 |
|---|---|---|---|
| HS 编码指南 | 2,156 | 3 | 4.3 |
| US26D / 626 / 630 表面处理代码 | 1,965 | 5 | 5.5 |
| 开门方向（左开右开） | 487 | 4 | 7.1 |

排名都在前 5–7 名，点击率却只有 0.1–0.8%。原因是**描述里已经把答案写完了**。比如 HS 编码那页的描述直接列出「门锁 8301.40、合页 8302.10……」，搜索的人在结果页就看到了，不需要再点进来。

这对 AI 引用是好事，对点击是坏事。

**做法：** 把这两页的描述改成「给一个答案 + 说清只有点进来才看得到的内容」，比如各国 8 位、10 位编码，以及印度、欧盟、美国的差别。已排进第 2 周的「改现有文章」，下周一用数据对照效果。

## 2. 工具页：值得试，但要对准具体搜索词

我们已有 3 个工具：锁芯计算器、产品查找器、配置器。28 天合计约 30 次曝光、0 次点击。原因是它们对应的不是哪个具体的搜索词。帖子说的正是这一点：一个具体需求对应一个工具。

按我们自己的搜索数据，候选如下：

| 工具 | 依据 |
|---|---|
| 门五金 HS 编码查询（输入品类 → 出编码） | HS 编码指南 28 天曝光 2,156；Bing AI「hsn code for hardware items」51 次 |
| 表面处理代码对照（US26D ↔ 626 ↔ 630 ↔ 652） | 「630 finish」137 次、「finish 630」24 次、「us26d」21 次 |
| 万能钥匙方案生成（几级、几把钥匙） | 「master key plan」68 次，排名 15.9；「great grand master key」22 次 |
| 开门方向判断 | 开门方向文章 487 次曝光 |

**建议：** 先做前两个，4 周后看数据再决定后两个。帖子作者做了 12 个，起来的只有 2 个，所以要小批试。

## 3. 垃圾外链 / disavow：先查一项，先别拒

- 你发的数据包里**没有外链数据**，现在不能确定我们有没有被批量加了垃圾外链。
- Google 的官方说法是：一般的垃圾外链会被自动忽略。disavow 只在两种情况下用：收到「人工处置」通知，或者自己买过链接。乱用会把好链接一起拒掉。
- 我们这次的下滑也不像外链惩罚。英文指南的排名基本没掉，曝光转到了其他语种；外链惩罚会是排名整体往下掉。

**你要做的（3 分钟）：** 在 GSC 查「人工处置」，并导出最新外链发给我。步骤在操作手册第一屏。

## 4. 每日清单、SOP 表、6 个月计划

- 清单里的大部分（购物车、促销、评价、结账）针对零售站，HYDE 不适用。
- 适用的已经自动化了：死链、缺图、页面错乱，每次发布前都会自动检查，不过就发不出去。
- 每天要人做的只有一件：**回复询盘**。表单 10-14 修好后，还差你提交一次真实询盘，确认邮件能收到。
- SOP 表和 6 个月计划是通用框架，和我们现在的做法方向一致：按搜索数据写文章、产品页结构化数据、每次发布有记录。没有需要新加的。
