# HYDE 产品图 AI 出图标准（给美工）

2026-10-14 · 依据：甲方 09-04、10-13 定的图片规矩，以及 10-14 全站图片审计的结果（`docs/research/image-audit/REPORT.md`）。

## 一句话

**AI 可以做场景，也可以重渲染产品，但出来的产品必须和该型号的实拍图一模一样，能让买家照着图下单、照着图装上门。** 有一处对不上，这张图就不能用，改用实拍图。

为什么这么严：买家买的是一整柜五金，到货以后改不了。孔位、螺丝、执手形状都是开模之前就定死的。AI 画出来的零件看着像，但孔位不对就装不上。懂行的买家一眼就能看出来，然后就不再相信我们其他的图。老板 09-04 的原话：「金属的孔位不对，螺丝不对，安装不上去，都不能用。」

## 一、三种做法，按优先级

| 优先级 | 做法 | 产品像素从哪来 | 什么时候用 |
|---|---|---|---|
| 1 | **实拍修图**：抠图、白底或灰底、调曝光、校正透视、去灰尘和反光、统一阴影 | 实拍照片本身 | 所有白底主图和图库图 |
| 2 | **实拍合成场景**：把实拍产品抠出来，放进 AI 生成或渲染的门、墙、房间里 | 实拍照片本身 | 安装效果图、氛围图 |
| 3 | **产品重渲染**：按实拍图和公布尺寸建 3D 模型，或用 AI 以图生图 | 3D 模型或 AI | 实拍缺某个角度、要换光换角度的时候 |

能用 1 就不用 2，能用 2 就不用 3。第 3 种每张都必须通过第五节的逐项对照。

**绝对禁止：**
- 用文字描述直接生成产品，比如「生成一个黑色逃生推杠」。只有文字、没有实拍参考出来的产品，一律不能用。
- 给产品加零件、减零件、改造型：多一个螺丝、少一个导向座、换一种执手弯度，都不行。
- 「补画」照片里看不到的部分，比如背面、内部、安装面。看不到就不画，构图时别让它出镜。
- 把工厂不成套卖的东西拼成「一套」；一张图里混用两种表面处理。
- 把别家的产品图、目录图（包括 KANEE）当产品参考。别家的图只能学版式和光影。

## 二、AI 工具怎么用

**参考图**
- 用该型号在网站上的**全部角度实拍图**，加上它的尺寸图。
- 干净原图在 `public/images/products/<型号文件名>.webp`，1000×1000，没有水印。
- 一个型号有哪几张图，看 `content/products/<slug>.json` 里的 `heroImage` 和 `gallery`。
- 不要用 `products-hyde/` 里加了水印的图做参考。

**做场景时把产品锁住**
- 优先做法：产品图层保持实拍像素，只让 AI 生成背景和门。用蒙版或局部重绘（inpainting）把产品区域保护起来，AI 只改蒙版外面。
- 如果一定要让 AI 重画产品（比如换光）：用轮廓或深度控制（ControlNet 的 canny / depth，或同类功能）锁住外形，重绘幅度调低。出图以后照样逐项对照。
- 场景里的门、墙、地面可以自由生成，但要符合第三节的安装逻辑。

**训练模型（LoRA 或同类）时**
- 一个型号训练一个模型，训练集只放这个型号的实拍图。不要混型号，不要混别家的图。
- 训练好的模型只代表「像这个型号」，不代表「就是这个型号」。每张出图都要做第五节的逐项对照，不能因为模型训练过就免检。
- 发现模型反复出同一种错误（比如螺丝数量总是错），就别再用它做那个部位：把那部分改回实拍像素。

**画面里不要有字**
- 不要有 logo、认证图标（CE、防火、逃生标志）、标准号（EN 1125、UL、TÜV）、宣传语。
- 水印由网站统一加；认证类说法必须先有证书才能上，图里不能先说。
- AI 生成的门牌、指示牌常常是乱码，要么去掉，要么换成空白。

## 三、场景逻辑：装门师傅看了会不会说「装错了」

| 产品 | 正确的样子 |
|---|---|
| 逃生推杠（305/306/307/308/311 等） | 只装在向疏散方向开的门上，装在**推开的那一面**。横杆水平，大约离地 900–1100 mm，几乎占满门宽。锁盒在**开启边**（门锁那一侧），看得见锁舌。垂直杆款（D 款）的上杆、下杆走到门顶和地面，导向座的数量和实拍一样。 |
| 外侧执手（trim） | 装在推杠所在门的**另一面**（拉的那一面），和推杠高度对应。 |
| 执手锁、锁体 | 把手中心离地大约 900–1050 mm。锁体在开启边，锁舌朝门框。执手方向和开门方向一致。锁芯孔在执手下方，方向和实拍一致。 |
| 合页 | 在门的**铰链边**，一扇门一般 3 个，最上和最下离门顶、门底大约 150–250 mm。 |
| 闭门器 | 在门的上沿，按臂型装在推开面或拉开面，不在门中间。 |
| 地弹簧、天地轴、玻璃门夹 | 地弹簧埋在转轴正下方的地面里；夹具在玻璃门的上角、下角。 |
| 无障碍扶手、浴凳 | 在卫生间瓷砖墙上，扶手大约离地 700–850 mm，不放在客厅。 |
| 门镜、插销、门吸 | 门镜在门中线、眼睛高度（约 1500 mm）；插销在门的上部或下部边缘；门吸在门开到底碰到的地面或墙上。 |
| 双开门 | 两扇不要都画成侧锁。没有中柱的双开门，侧锁的锁盒不会在两扇门的碰口中间。 |

通用要求：
- 门宽按 900 mm、门高按 2100 mm 估算比例，产品在门上的大小要合理。
- 一张图一种表面处理：拉丝不锈钢就全是拉丝，黑色就全黑。
- 不要把我们的小五金和重型工业设备放在同一个画面里。

## 四、合成的光影要求

- 光的方向、软硬、色温，产品和场景要一致。
- 产品和门、墙之间要有接触阴影，不能像贴上去的。
- 透视要一致：门是斜着拍的，产品也要斜；镜头高度一致。
- 抠图边缘不能有白边、毛边、残留的原背景。
- 金属反光要来自场景里的光，不要保留原棚拍的白色反光块。

## 五、交付前逐项对照（每张都做，不做不交）

把出图和该型号的实拍图**并排放在一起**，一项一项打勾：

| # | 检查项 | 怎么查 |
|---|---|---|
| 1 | 孔的位置和数量 | 数面板、底座上的孔，位置和实拍一致 |
| 2 | 螺丝的数量和位置 | 数螺丝，看位置、头型 |
| 3 | 执手 / 推杠 / 拉手的轮廓和粗细 | 弯度、截面、端头形状 |
| 4 | 比例 | 用公布尺寸核对：面板长度、中心距、推杠长度、杆径 |
| 5 | 锁芯和钥匙孔 | 形状（欧标 / 圆形）、方向（上下） |
| 6 | 零件数量 | 不多不少：导向座、盖帽、锁盒、杆、螺丝 |
| 7 | 表面处理和颜色 | 和实拍一致，画面里只有一种 |
| 8 | 安装逻辑（场景图） | 按第三节：门型、开启边 / 铰链边、高度、朝向、比例 |
| 9 | 画面文字 | 没有 logo、认证图标、标准号、乱码标牌 |

**一项不过，这张就不交，改用实拍图。** 不要靠修补蒙混过关。

## 六、交付规格

| 项目 | 要求 |
|---|---|
| 白底图库图 | 1000×1000，正方形，WebP 或高质量 JPG，产品完整、居中 |
| 场景 / 氛围图 | 1600×1100 或 1000×1000，WebP 或高质量 JPG |
| 命名 | `<slug>-scene-1.webp`、`<slug>-scene-2.webp`……，新增在图库里，**不要覆盖实拍图**，实拍白底图是规格依据 |
| 水印 | 不要自己加，网站统一加 |
| 附带记录 | 每张一行：型号、用了哪几张实拍做参考（文件名）、做法（修图 / 合成 / 重渲染）、场景说明（门型、装在哪一边、高度）、第五节九项的结果 |
| 附带对照图 | 重渲染和合成场景都附一张「出图 + 实拍」并排图 |
| 第一批 | 先交 5 张样图给甲方看，方向定了再批量做 |

## 七、这次全站审计里看到的错误（照着避开）

10-14 审了全站 2,798 张图，详细结果见 `docs/research/image-audit/REPORT.md`：
- 渲染、AI、合成和图文图共 963 张逐张对照：通过 514，**不通过 247**，另有 202 张所属型号没有一张实拍可以对照。
- 不通过的主要原因按出现次数排：外形、孔位、螺丝和实拍不一致（86），同框混了两种表面（64），文字拼错或标注和规格不符（53），多出零件或拼了别的型号（52），安装逻辑错（34），未核实的认证说法（28）。

每一类各举几个真实例子：

**外形、孔位、螺丝画错**
- 19-130MM 玻璃门拉手：底板画了 2 个孔，实拍和尺寸图都是 4 个。
- 803、808、819 执手：执手杆整根没画，钥匙直接插在圆柱上。
- 308-D、309-D：杆上多画了导向座，实拍和尺寸图里没有这么多。
- SSH023 合页：每页画了 3 个孔，实拍是 4 个。

**同框混了两种表面**
- 70610-AB：青古铜执手配银色锁舌面板。
- DV 系列门镜：黑色门镜配黄铜把手。
- EH01–EH03：黑色执手配黄铜锁芯。

**多出零件、拼了别的型号**
- D101、D102 单头锁：场景里加了一套球锁或执手锁，这个型号不含。
- 9014 执手：画面里多了四舌锁体和锁芯；9014 SSBK 规格是浴室隐私款，内侧旋钮，本来就没有钥匙锁芯。

**安装逻辑错**
- 316-S、330、306-S：推杠装在拉的那一面（画面里看得到合页轴）。
- 312：锁侧组件装在合页一侧。
- FB014、FB016 插销：装在合页侧，或装在单开门的门扇正面。
- BH01、BH02 扶手：装在玻璃淋浴门或玻璃隔断上。
- AR4-140：铝门锁装在实木门上。

**未核实的认证和性能说法**
- 305、306、309、315、033、037 等：图里有 CE、UL、EN 1125、防火图标，或者写着「FOR FIRE DOORS」。
- SH01：门上贴了 ABNT P-90 标牌。
- BH56、BH58：写了 150KG / 100KG 承重。

**AI 乱写的字**
- 多张锁芯色板图把 Satin 拼成「Stain」。
- 「COMPLETE ACCESSOIRES」「MOOTH CLOSING」这类拼写错误。
- 门牌、手册上的字是镜像乱码。

**门镜画成一个光点**
- DV08–DV12：场景里的门镜只画成一个发光小点，看不出外形。DV11 实物是方形的，图里却是圆点。

这些错误都是第五节九项检查能拦住的。交图前逐项打勾，就不会再上线。
