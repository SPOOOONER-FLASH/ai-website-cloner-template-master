## ① 长标题能不能省掉品牌名

## ② GSC 全站导出

这次发来的导出**只筛了一个页面**（HS 编码指南），看不到全站。请这样导：

1. 打开 https://search.google.com/search-console ，选 **cantonlock.com**。
2. 左侧 **效果** →「搜索结果」。
3. 顶部如果有「网页: …」之类的筛选条件，点它旁边的 **×** 去掉，保证**没有任何筛选**。
4. 点日期 → 选 **比较** → **过去 28 天与上一时段比较** → **应用**。
5. 右上角 **导出** → **下载 CSV**（会下载一个 ZIP）。

**成功的样子**：ZIP 里有「查询」「网页」「国家/地区」「设备」「日期」几份 CSV，且「网页」那份有很多行，不只一行。
