## 六、本轮顺手修掉的两个真问题

**一、`cn()` 一直在静默删掉自定义字号类。** `cn("text-h1 text-ink")` 返回的是
`"text-ink"` —— tailwind-merge 把 `text-h1` 当成了颜色类。首页 h1 因此按 16px 渲染。
没有类型错误、没有 lint 警告、没有测试报警，是在手机视口量 DOM 才发现的。
已加 `extendTailwindMerge` 与四项断言。（提交 `5f0b3e6219`）

**二、Tailwind 把构建产物当源码扫描。** `out/` 与 `out-rayen/` 是提交进仓库的，
Tailwind v4 自动探测只跳过 `.gitignore` 的路径，于是约 2,350 个生成 HTML 被当成源码。
其中一个文件里类名落在 RSC 分片边界上被截断，Tailwind 提取出非法候选类，
生成的 CSS 让 PostCSS 无法解析，`next dev` 全站 500。
**一个生成文件里的一个截断字符串让本地整站挂掉，而源码一行没改。**
已加 `@source not`。（提交 `b9cdbcacb7`）

**三、FAQ 的 OEM 答复写着「435 models」，实际发布 361。** 435 是某个时点的记录数，
而当时目录已有 462 条记录、其中 361 条有照片。**一个数字同时错了两个方向，
出现在商业上最重要的一条 FAQ 上，而这个站的全部论点就是它的数字可信。**
已改成 361，并加 `src/lib/published-counts.test.ts` 锁住 —— 它拦不住数字变旧，
但能拦住带着错数字的构建上线。
