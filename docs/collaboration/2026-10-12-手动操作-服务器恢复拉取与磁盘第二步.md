## 第一部分：用只读令牌恢复拉取（约 10 分钟）

**1. 在 GitHub 生成令牌**（电脑浏览器，已登录）：

1. 打开 `https://github.com/settings/personal-access-tokens/new`
2. **Token name** 填 `cantonlock server`；**Expiration** 选 `366 days`（或最长那个）。
3. **Repository access** 选 **Only select repositories**，下拉里只选 `ai-website-cloner-template-master`。
4. **Permissions** → **Repository permissions** → **Contents** 选 **Read-only**。其他都不要动。
5. 拉到底点 **Generate token**，再点 **Generate token** 确认。
6. 页面上出现一串以 `github_pat_` 开头的字，点旁边的复制按钮。**这串字只显示一次，也不要发给我或任何人。**

**2. 在宝塔终端里，一次粘贴下面这一整段**，回车：

```bash
cd /www/wwwroot/cantonlock.com && git config --unset core.sshCommand; git remote set-url origin https://github.com/SPOOOONER-FLASH/ai-website-cloner-template-master.git && git config credential.helper store && read -rs -p "粘贴令牌后回车：" T && printf 'https://SPOOOONER-FLASH:%s@github.com\n' "$T" > /root/.git-credentials && chmod 600 /root/.git-credentials && unset T && echo && echo 已保存
```

它会显示 `粘贴令牌后回车：`。这时粘贴第 1 步复制的令牌（**粘贴后屏幕上什么都不显示，是正常的**，为了不让别人看到），回车。成功会显示 `已保存`。

**3. 立刻部署一次**：

```bash
flock -w 600 /tmp/cantonlock-deploy.lock /usr/local/bin/cantonlock-deploy.sh; tail -3 /var/log/cantonlock-deploy.log; git log -1 --oneline
```

可能要等一两分钟，期间没有输出是正常的。

**成功的样子**：最后一行的版本号**不再是** `e01d2e8d1d7`。
**如果还是 `Repository not found` 或 `Authentication failed`**：停在这里，截图发我，不要重复生成令牌。

这一步改坏不了网站：拉不到时，网站继续用现在这一版。

**4. 账号申诉还要做**（如果 10-10 那份文件的第二部分还没做）：登录后打开 `https://support.github.com/contact`，英文申诉内容在桌面 `hyde\00-先看这里-人工待办\2026-10-10-手动操作-GitHub账号被隐藏.docx` 第二部分，直接复制。申诉通过后，deploy key 也会恢复可用，到时可以删掉这个令牌。
