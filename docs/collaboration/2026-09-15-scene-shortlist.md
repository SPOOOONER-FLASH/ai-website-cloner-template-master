# 适合拍这种场景的产品 — 选品清单

生成的：`npm run brief:scenes`。配套 `2026-09-15-catalogue-scene-style.md`（零件表与布光配方）。

## 判据

甲方给的二十多个跨页全都建立在同一个动作上：**同一个形状、两个以上表面、放在一起**。
没有这个，画面就塌回成「一个物件放在好看的背景上」——那是另一种、而且弱得多的图。

所以门槛是：**这个形状有没有两个以上表面，而且每个表面都有自己的照片。**
询盘只用来排序通过门槛的，不能反过来 —— 五十个询盘但只有一个表面的型号，
根本做不了这种图。

第二道门槛是**尺寸**。1050mm 的推杠不会摆在石板上跟树枝合影，它是建筑不是物件。

## 二、不要用这几个（尺寸不对，不是不重要）
