## 二、FAB：只用已公开的事实

规则：Feature 必须是站上已经公开的事实；Advantage / Benefit 是翻译，不许新增数字。

| Feature（已公开） | Advantage | Benefit（买家在乎的结果） |
|---|---|---|
| 工厂自产，1998 年起（llms.txt、公司页） | 不是贸易商，问题能追到产线 | 出错时有人负责，不用在两家之间传话 |
| 521 个型号、16 个品类（目录实时计数） | 一家配齐一张门表 | 少管几个供应商，一次验货一个柜 |
| 交期 30 天起（甲方 09-01 确认） | 可以按项目排期倒推下单 | 不因五金拖工程节点 |
| 逐型号公开检测报告（下载中心） | 报告对应到型号，不是「系列通用」 | 送审和进口清关时拿得出对应文件 |
| 尺寸、backset、中心距逐型号写在规格表里；缺的写「—」 | 不编数字 | 下单前就能核对孔位，不会整柜装不上 |
| OEM / 贴牌（`/services/`） | 按买家品牌出货 | 分销商做自己的品牌，不和别人比同一个型号的价 |

**写作用法**：Feature 放产品页；Advantage 放对比页和分类页「怎么选」；Benefit 放文章标题和 FAQ 问句——那一层才是买家搜的和 AI 引用的。

## 四、主题集群 → 现有文章 → 分类页的连接

82 篇文章（指南 45 + 新闻 37）里，**34 篇指南的 `relatedModels` 是空的**，所以新上线的分类页「怎么选」区块暂时连不到它们（例：`hinge-grades-and-count`、`stainless-grade-selection-201-304-316`、`master-key-hierarchy-planning`）。
下一步最便宜的内链收益：给这 34 篇逐篇补 `relatedModels`（只写正文里确实讨论的型号），每补一篇，对应分类页自动多一条「下单前先读」。这是内容元数据，归 Claude 文案线，一次一批。

## 五、要甲方提供的东西（按价值排序）

1. **最好的 10–20 个客户的共性**：国家、类型（分销 / 项目 / 品牌）、首单是什么品类、为什么选我们。不要名字，要共性。这是 ICP 从假设变成事实的唯一办法。
2. **2–3 个能公开的交付案例**：品类、数量级、从下单到出货几天、遇到的问题怎么解决。可以匿名。
3. **车间 / 质检的真实照片和数字**：例如某条线的日产能、抽检比例。只要愿意公开的。
4. **展会名片跟进**：BAU 2027 之后买家会搜公司名。品牌词（Canton Hyland / HYDE）能不能搜到、搜到什么，建议展前自查一次。
