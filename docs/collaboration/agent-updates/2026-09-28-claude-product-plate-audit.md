# 2026-09-28 · Claude（工程）· 产品主图一致性审计（目标 #83）

**来源**：甲方 09-23「同类产品统一底色、视觉占比、基线和周围留白」；09-28 月度核查列为未完成。

**做了什么**：`node scripts/audit-product-plates.mjs` 生成 `docs/research/product-plate-audit.md`（及 `.json`）。
测的是站上实际显示的 products-hyde 版主图，每个品类和本品类的中位数比较，测四项：主体占比、底边留白（基线）、居中、底色。

**结果**：HYDE 有主图的 521 个产品里，54 张需要看，多数是主体偏小（23 张）和基线偏（22 张）。

**校准过程**：
- 第一次测的是未加水印的原图，151 张报「多处标记」。原因是原图里还带着旧 Hyland logo。
- 改测站上显示的版本后，发现 HYDE 标记在四个角都可能出现。于是改为：整块落在角落的小块才认作品牌标记，产品本身的像素一个都不遮。
- 抽查 BH10（主体偏小）、AAH024（误报已消除）、026（散放配件）、BH02（基线偏），判断都对得上。

**下一步**：修图归视觉会话。只允许清理真实照片：留白、居中、底色；不得生成或改动产品本身。改完重跑脚本。
