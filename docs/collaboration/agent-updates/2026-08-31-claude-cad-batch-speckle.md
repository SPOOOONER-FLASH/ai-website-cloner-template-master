## 三、三处**故意没写**的，按纪律留给人判断

1. **`026` 的 65 vs 66** ⚠ 最重要的一条。
   记录里写 `Rosette Diameter = 65mm`，图纸在右侧圆形安装件上印的是 **66**。
   差一毫米正是这个任务存在的理由，而且两者**可能根本不是同一个部位** ——
   66 标在锁芯壳体上，不在座上。**请甲方确认哪个是 rosette 再动那一行。**
2. **`lh1016` 的 138–165mm 与 55mm**。前者是装配后跨两个座加一扇门的跨距，
   不是执手本身的属性；后者图上没命名，可能是执手直段也可能是偏移。都没写。
3. **`bh33` 的 Length**。图纸标题是 `Length: 600`，记录是 `450mm/600mm`。
   这不是矛盾 —— 图纸画的是两种长度里的 600 那款，所以 Length 行保持不动。

## 四、方法确认：speckle 排名是对的，直接看图比 OCR 好

甲方建议上 OCR（数 `\d+\s*mm` 出现 3 次以上）。**我没走这条路，因为不需要。**
我可以直接读图片，而读图比 OCR 强在关键的一点上：OCR 能告诉你纸上有「135mm」，
**但不能告诉你 135 是执手长度还是别的什么**。而任务书三条纪律里有两条
（不从兄弟型号推断、没命名的别贴术语）恰恰是关于**判断哪个数字是什么**的。
OCR 会把这个判断交回给人，等于没省事。

按排名开图的命中率：**这一批开 5 张（含核实用的那张照片），4 张是图纸。**
与任务书记录的「按排名开 8 张全中」一致。排名可信，继续用。
