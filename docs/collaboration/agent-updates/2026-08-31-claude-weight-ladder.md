## 甲方说「乱加粗、没有章法」—— 是字面意义上的没有章法

```
改前   h1  700 bold
       h2  400 regular   ← 比 h3 还轻
       h3  700 bold
       c1  400 regular
```

**二级标题的字重低于三级标题。** 页面上没有任何东西告诉读者两个标题谁大谁小，
加粗因此不再携带信息，只剩噪音。这不是审美问题，是逻辑错误。

改后单调递减，且不跳级：

| | 改前 | 改后 |
|---|---|---|
| h1 | 700 | 700 |
| h2 | **400** | **600** |
| h3 | **700** | **600** |
| c1 / c2 | 400 | 400 |

Archivo 从 Google Fonts 载入的是 `wght@400;600;700`，600 是真字重，不会触发合成粗体。

## 字距：阅读尺寸不该有正字距

每一级原本都带 ~0.36px 字距，正文也带。正字距是给小字号和全大写用的装置；
16px 以上只是把词推开、每段多占一行。

| | 改前 | 改后 |
|---|---|---|
| h1 | 0.052rem | **-0.02rem** |
| h2 | 0.048rem | **0** |
| h3 | 0.02rem | **0** |
| c1 | 0.02rem | **0** |
| c2 | 0.024rem | 0.024rem（13px 小字保留） |

## `.text-lead`：导语不该是标题

类目页的摘要句用的是 `.text-h3`，于是 h1 正下方是一段**三行半粗体**，
页面出现两个互相竞争的标题、没有明确入口 —— 这就是「看着像一堵墙」的来源。

新增 `.text-lead`：h3 的字号、正文的字重、满黑。导语靠**尺寸和墨色**取得分量，
不靠字重；加粗留给真正是标题的东西。这条正是亚马逊在更小正文字号下反而更透气的原因，
也是它唯一值得我们照搬的排版规则 —— 它不是消费零售的点子，是任何密集目录都适用的。

同时把类目页目录区的 `mt-144` 改成 `mt-64 md:mt-144 lg:mt-288`。
144px 是在 1512px 上量出来的两个通栏之间的间距，在 375px 上是一整屏空白。

## 锁定

`type-scale.test.ts` 新增两条：

1. 字重随标题层级下降不得上升（h1 ≥ h2 ≥ h3 > 正文）；
2. h2 / h3 / c1 的字距必须 ≤ 0。

## 我们是 B2B，从 B2C 借什么、不借什么

**借**：单调字重阶梯、阅读尺寸零字距、黑/灰二分承担主次、导语不加粗。
这四条都不是零售策略，是密集信息可扫读的通用条件。

**不借**：亚马逊的信息密度和促销色块（我们没有价格、评分、Prime 标），
香奈儿的大图叙事节奏（我们的访客是来查型号和规格的，不是来看时装片的）。
我们的版式目标是**规格表好读、型号好找、联系方式好按**，不是逛。
