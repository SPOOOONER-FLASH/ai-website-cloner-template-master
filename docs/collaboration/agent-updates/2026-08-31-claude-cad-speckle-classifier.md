## 1. 前三次判据为什么都错

记录在案的三条弯路（纯黑墨水、长直线、纸白无中间灰）**量的都是墨水本身**。
但两类图的墨水其实很像：图纸的线是抗锯齿灰，产品照的背景也是纯白。

分开它们的不是墨水，是墨水**有多孤立**：

- 产品照是实心物体 —— 绝大多数暗像素周围还是暗像素，那是物体的内部。
- 图纸是细线加小字 —— 绝大多数暗像素周围是纸。

`speckle` = 8 邻域里浅色占多数的暗像素比例。一行代码，不需要 OCR。

**实测（全库 1478 张）**

| 集合 | speckle | 排名 |
|---|---|---|
| 19 张人工确认的图纸 | 0.53 – 0.99 | 18 张进前 84 |
| 14 张人工确认的产品照 | 0.01 – 0.18 | 109 名以后 |
| 中间地带 | **无样本** | |

**盲测**：按旧清单开 6 张 → 0 张图纸。按新排序开 8 张 → **8 张全是图纸**。

⚠ **一个已知反例**：`lc9045-lock-case.webp` 是真图纸却排第 1074 ——
它是深色渲染图，只印了 90 和 45 两个数字，没有细线也没有小字。
**分数低不是"这不是图纸"的证据**，只能用来排先后。这条写进脚本头注和任务书了。

## 2. 新写入 8 个产品

| 产品 | 图纸给出的 |
|---|---|
| 036 | 200 × 190mm，杆截面 4mm，侧板 20mm |
| 001 | 外执手板 300 × 75 × 1.5mm，把手中心距 179mm，出手 60mm，锁芯孔 Ø32mm |
| 030 | 外执手板 178 × 52mm，执手长 140mm，截面 22.5mm，出手 40mm |
| 9003E | 执手 133mm，座径 53mm，截面 19mm，座厚 8mm，方轴 8mm，出手 62mm |
| 9007S | 执手 132mm，座径 53mm，截面 19mm，座厚 8mm，方轴 8mm，出手 63mm |
| NC182 | 执手 86mm，截面 38mm，下垂 49mm，方轴 8mm |
| BH41 | 高 45mm，出挑 45mm，离墙 18.5mm，杆截面 8mm |
| F101 | 面板厚 1mm，箱体 308 × 108mm，箱深 40.5mm |

**三条纪律都守住了**

1. **9003E 和 9007S 是同座同轴，只差 1mm**（133/62 对 132/63）。两张图分别读的，不是抄的
   —— 这正是文档里警告的那种近似陷阱。
2. **001 和 030 的图纸画的是外执手板，不是推杆本身。** 行标签写成 Plate / Lever，
   免得有人把 300mm 读成推杆宽度。
3. **F101 的图纸是「印证」不是「推翻」**：已有的 `Size = 129*321.5mm` 就是面板尺寸。
   所以没有加重复的 Plate size 行，只补了它缺的三行（面板是盖在更小的箱体上的）。
   第一版我加了 Plate size，发现和 Size 是同一组数字反着写，已回滚重做。
