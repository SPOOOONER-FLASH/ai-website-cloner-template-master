## 和移交文件对不上的一处

移交写「p29–p52 锌合金分体」。实际 p29–p31 还是凯撒系列（早已上架），p32 是锁体/锁芯页，锌合金从 **p33** 起。

## 读数上值得记住的

- 型号前缀是底座：A5 圆、A9 方、A38/A39 装饰座、A40 无底座。
- **CP = 亮铬，PC = 白色**，只差字母顺序。CS 是新代号，甲方 09-23 定名「拉丝铬」（图册印「铬拉丝」，同义，两种都认）。
- 座径不全是 52：A38-786 **Ø53.7**、A5-348 Ø54、KA82-9910 Ø50 —— 放大读的，第一眼差点记成 52。
- p35 / p47 一个面板两个型号（方座 A9- 与圆座 A5-），图纸只画方座 → 圆座款不写尺寸（heldBack）。
- A5-2011 场景照书架上有 KINFOLK 杂志书脊 → 贴左下裁掉。
- p52 是卡片版式，没有规格栏 → 那 6 个只写总长、座尺寸、材质。
