## 加的是什么，为什么

复盘第 8、9 份报告的结论是：被引用最多的是「A 和 B 哪个好、什么时候选哪个」。
这三篇原本都只有一半是比较，另一半是定义。补的全部是前者。

**旧锁**（原本纯故事，0 引用，最难写出增量）
- 弹子锁之前那套机构到底挡住了什么、挡不住什么（骷髅钥匙的名字就来自于此）
- 结束它的三个专利，都带年份和法域：Barron 1778（英）、Chubb detector 1818、
  Yale 弹子筒 1860 年代（美）。**并且立刻自我否定**：这些都不能给照片里那把锁断代，
  因为暗簧挂锁至今还在生产 —— 这一段是全文可信度最高的地方，不能省
- 「你自己怎么读一把旧锁」：锈会先吃掉哪一样（厂名钢印），所以别上钢丝刷
- 补一句我们不做挂锁，目录里一把都没有（`grep -il padlock content/products` = 0）

**不锈钢**
- 钝化膜机理：为什么氯离子造成的是点蚀不是面锈，钼为什么是针对这个机理的
- **201 不只是镍低**：ASTM A240 里 201 的铬是 16.0–18.0%，304 是 18.0–20.0%。
  铬才是成膜的那个元素，这一条在「便宜是因为省镍」的说法里被丢掉了
- PREN 公式给出来，**同时写明它高估含氮的 200 系**，不能拿来论证 201 能上海边
- 「不是金属的错的那种锈」：茶渍锈 / 点蚀 / 游离铁污染三者的区别 ——
  第三种是现场钢丝刷和角磨机粉尘造成的，316 上长得一模一样
- EN 10204 的 2.1 / 2.2 / 3.1 / 3.2 四类证书差在哪，以及两条边界：
  炉号证书覆盖的是原料一炉不是成品，外壳的证书不代表里面的方轴和螺丝

**窄边铝门**
- 五分钟现场判断：锁边缝隙上下是否平行、锁舌在锁板上的亮痕在孔的哪一侧、
  抬自由边有没有旷量、量对角线。失效顺序就是维修顺序
- 地弹簧 / 上下轴 / 偏心轴 / 合页四者的**载荷路径**对比 —— 不是四档质量，是四个去处
- 询价必须带的六个数字
