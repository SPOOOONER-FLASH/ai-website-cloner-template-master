## 一遍一遍看页面看出来的

| 问题 | 改法 |
|---|---|
| 第一版印刷版 72 页，超过 70 | 小类把一两张卡片单独剩在一页上（门锁最后一页只有 1 张）。省得下一整页时，横幅页改放 3 行 |
| 8 个「Also available」页面几乎是空的，2–33 行 | 全书合成一个「Models without a photograph」名册放在书末，约 1.5 页，省 4 页 |
| 地弹簧卡片没有规格 | 默认的 Material/Finish/Size 和地弹簧的数据不对应。改为每类按自己产品最常填的标签排序 |
| 「Max door width (spindle to edge)」压在数值上 | 数值宽度改为按标签实际宽度留空；新增测试检查两本**每一页**同一行文字是否重叠，并且用旧代码验证过它确实会失败 |
| 一个型号被省略号截断 | 型号截断等于下不了单。型号改为先缩小字号再折行，永不截断 |
| 地弹簧满页开篇中间一片空白 | 没有抠好的主图，改用横幅开篇直接进产品 |
| 电子版 18.3 MB | 只对电子版降到 150 dpi：9.4 MB。印刷版保留全部像素 |

## 处理方式需要甲方知道的

- **4 个玻璃门上夹（D-1042、D-1043、D-3017、D-3018）不配图**，放进书末名册。
  它们的照片是供应商画册截图，左边被裁掉，看不到整个零件，底边还有中文字样。
  按 AGENTS.md 的规矩：买家拿着这张图去车间订不了货，就不能用。**这几张图目前也在官网上。**
- **另外 24 个地弹簧和顶轴**是深色背景的画册截图，照片是真的，所以印了，但看起来像来自另一本书。
- 款式差异合并成一张卡片的条件很严：名称和所有非表面规格都一致才合并，549 → 542。
  按型号前缀粗合并会得到 532，但多出的那 10 个其实尺寸不同。
