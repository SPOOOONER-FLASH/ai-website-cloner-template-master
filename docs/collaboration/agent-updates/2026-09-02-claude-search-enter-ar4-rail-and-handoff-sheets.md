## 一、搜索框「按回车不管用」—— 是真的坏，不是错觉

上一轮我说「搜索没坏，是 D103 不在目录里」。**那个回答只对了一半，另一半是我漏看的。**

`onSubmit` 的实现是 `preventDefault()` 之后，只在 `results.length === 1` 时关闭弹窗，
其余情况**什么都不做**。从访客那边看，这和一个坏掉的输入框完全没有区别 —— 他们用过的
每一个搜索框按回车都会去到某个地方。

改成：回车打开第一条结果；没有精确结果时打开最接近的型号；两者都没有才不动。
没有 `/search?q=` 页可去（索引在客户端、站点是静态导出），所以目的地就是已经算好的
最佳匹配。结果计数旁加了一行 "Press Enter to open the first"。

**静态导出实测**：输入 `D103` 回车 → `/products/deadbolts/d101-ab-deadbolts/`，弹窗关闭。

### 第二个问题：近似建议被挤出屏幕

近似型号列表原本渲染在常驻建议区**之后**。查 D103 无结果时，先出现的是六个类目胶囊
加六个热门型号 —— 客户在手机上看到的是「MAIN CATEGORIES」，据此判断搜索坏了。
**按可见内容，这个判断是对的。** 回答排到常驻菜单之前。

实测弹窗文本首行现在是：`No exact match. The closest models we publish:` 紧跟 D101 五个
变体和 D102。

> 教训记一下：上一轮我用「搜索逻辑是否返回正确结果」验证了搜索，然后宣布它没问题。
> 客户报的是「按回车没反应」，那是**提交路径**，我根本没测。功能对不对和用起来是不是
> 死的，是两个问题。

## 二、Argentina AR-4 手机端改横向滑轨

`grid-cols-1` 让四张方图卡纵向堆叠，一个季节性模块在 375px 上占掉约 1790px、三个半屏，
后面的首页栏目实际上到不了。

改成 scroll-snap 横轨，与 `PageTeaserModule` 同一写法（原生 CSS，无 JS、无箭头、无自动
播放）。卡片宽 74%，让下一张始终露出一截 —— 那截是告诉拇指「还有」的唯一信号。
`sm` 断点以上仍是原来的网格，桌面端没有变化。

静态导出实测 375px：轨道 343 宽、内容 1063、卡片 254、区块高度 937（原约 2300）。

**踩到一个坑，值得写下来**：dev server 上量到卡片 1101px 宽、`min-width: auto`，看起来
像 flex 布局写错了。实际是 **Tailwind v4 的 dev CSS 没有为新写的 `w-[74%]` /
`min-w-[74%]` 生成规则**（同一行的 `snap-start`、`sm:w-auto` 都生成了）。生产构建
`out/_next/static/chunks/*.css` 里 `.w-\[74\%\]{width:74%}` 是在的。
**在 dev 上量任意值工具类，量到的可能是上一次的 CSS。以 `out/` 为准。**

### `scripts/build-submit-list.mjs` → 需要手动提交的网址

Bing / Yandex / Naver / Seznam 走 IndexNow，一次推完 969 条、不限量，**从来不是需要省
着用的东西**。Google 没有 IndexNow，只有 Search Console 每天十几条的配额。所以清单排过
序：第一组是与指定基准相比新增的 URL（本次 34 条 = 15 compare + 19 collections），
它们没有任何抓取历史，手动提交对这一类效果最明显。

`--since <ref>` 指定对比基准。默认 `HEAD` 的语义是「本次构建比上一次已提交构建多了
什么」—— 发布提交之后再跑会读到 0，那是对的，不是故障。

两个脚本都支持 `--out <dir>`，写一份中文命名的副本到交接文件夹。`npm run sheets` 一次
重跑两份。

## 五、AGENTS.md：自动压缩纪律

客户要求「自动压缩，artifacts 请保留」。

**前半句工具已经做了**，不需要本仓库加任何东西：Claude Code 按 token 比例自行压缩
（约 85% 警告、93% 强制），除非设了 `CLAUDE_CODE_DISABLE_AUTO_COMPACT`；它不会在工具
调用中间切断，会保留最近的消息。一个以为自己能调度压缩的会话，是搞错了它能看见什么。

**后半句才是我们的事。** 压缩保留的是对话摘要，对工作本身只保留已经落盘的部分。补了
一张表说明什么算 artifact，以及最常被破坏的那条：**生成物要写生成器，不要写输出**。
手工粘贴的表格在数字过期那一刻就废了，而且后来的会话无法判断「75 个产品没有主图」
是否还成立。

- `w-[74%]` 依赖 Tailwind 生成任意值工具类。若将来有人改动 `cn()` 合并或 content 扫描
  范围，卡片会退回内容宽度（图片原生 1100px），横轨会变成一张卡一屏。生产 CSS 里已有
  该规则，构建时会一起验证。
