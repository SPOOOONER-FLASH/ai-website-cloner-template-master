# 2026-09-28 · Claude（工程）· 首页轮播「不轮播了」（目标 #91）

**原因（已实测确认）**：鼠标一进入整个轮播区域（`<section>` 上的 onMouseEnter），自动播放就暂停。首屏大图几乎占满第一屏，鼠标自然停在上面，轮播就一直不动。
线上用 Playwright 把鼠标停在大图上，14 秒内一张都没换；不碰鼠标时约每 6 秒切一张。
手机上更糟：轻触或滑动会触发 mouseenter，却没有 mouseleave，滑一次就永久停了。

**修法**（`src/components/site/HeroCarousel.tsx`）：
- 悬停暂停只在文字说明区生效，而且只认真正的鼠标（pointerType === "mouse"）。这是没有手动按钮时鼠标用户唯一的暂停方式，所以不取消；键盘聚焦暂停照旧。
- 切换时等两帧动画的同时加 120ms 定时兜底。原来只等 rAF，在后台标签页或部分内嵌网页里会卡在第一张，和菜单抽屉是同一类问题。
- 新增守卫测试 `src/components/site/hero-carousel-autoplay.test.ts`。

**本地实测（Playwright，页面可见、正常出帧）**：不动鼠标时轮播；鼠标在大图上照常轮播；鼠标在文字说明上暂停；离开后恢复。
按设计仍会暂停的情况：后台标签页、系统开了「减少动画」、手机省流量或 2G。
