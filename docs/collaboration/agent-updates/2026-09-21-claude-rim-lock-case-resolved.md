## 工厂表说了什么

客户 2026-09-21 发来工厂规格表截图，两款外装锁：

```
1.大亮：1.5mm  尺寸100*85*25  喷灰色
  2.铜拉勾,铜方舌,铁装饰拉手  3.锁芯：前6珠铜头,后锁头4珠全铜  3条2.2mm S槽铜钥匙   33

1.大亮：1.2mm  尺寸100*85*25  喷灰色黄色
  2.铜拉勾,铁方舌镀彩锌,铜斜舌  3.锁芯：5珠铜头,后3珠实心铜头  5条2.2mm S槽铜钥匙   27.7
```

**「大亮 1.5mm / 1.2mm」后面紧跟「尺寸 100*85*25」,所以它是钢板厚度。** 这些外装锁的壳体是钣金冲压件,不是锌合金压铸。**1.2mm 是真的。**

## 处理:删掉模板行,而不是改写它

那条 `Chassis = Zinc die-cast case, zinc-plated steel internal components` 被**删掉**了(15 款 × 三语 = **45 行**)。

删而不是改,因为它整条都没有依据:
- 壳体部分被工厂表否定;
- 「内部件镀锌钢」部分同样没有来源,而且和 5835 自己 `Material` 行写的「锌合金与铜合金内部件」也对不上。

删一条没有依据的行不丢任何已核实信息 —— `Material` 行本来就写着壳体和内部件。

## 工厂表还纠正了三处我们写错的

| | 5836(灰) | 5835(金) |
|---|---|---|
| 壳体板厚 | 1.2mm → **1.5mm** | 1.2mm(不变) |
| 配钥匙 | 4 → **3** | 4 → **5** |
| 方舌 | 「铜或铁」→ **铜** | 「铜或铁」→ **铁镀彩锌** |
| 外形尺寸 | 新增 **100 × 85 × 25mm** | 同 |

**「4 条钥匙」是我昨天从西语经销商文本(`4 llaves`)里拿的,是错的。** 工厂表说 3 和 5。这印证了昨天那条判断:那份西语资料整体不可靠,不只是语言放错了位置。

## 一个必须写明的假设

工厂表上 `MODEL:` 栏是**空的**。5835/5836 的对应关系是**靠照片认的**:

| 表 | 特征 | 我们的产品 |
|---|---|---|
| 上行 | 喷灰色、铜方舌 | 5836 照片是灰色,方舌黄铜色 |
| 下行 | 喷灰色黄色、铁方舌镀彩锌 | 5835 照片是金色,虹彩镀锌件清晰可见 |

四个特征对得上,但**照片比对不等于型号比对**。如果反了,1.5/1.2mm 和 3/5 条钥匙就全反了。已在 runbook 里请客户回一句「对」或「反了」。

表上的 **33 / 27.7 没有标签**(可能是重量或价格),**一律没有使用**。
