The existing all-uppercase standalone headings will render as H2; explicit `## Heading` / `### Heading` is preferred for new body entries. No new content schema is required: `body`, `bodyEs`, `bodyPt` remain string arrays.
- A table is ONE body-array string, with newline-separated Markdown rows: `| Column A | Column B |\n| --- | --- |\n| Value A | Value B |`. Every data row must match header width; escape a literal pipe as `\|`. Keep the preceding heading meaningful; it becomes the table caption. Malformed tables fall back to visible plain text, never silently discard rows. Do not squeeze reference tables into a prose paragraph and expect a renderer to infer the columns.

Pure numeric columns can sort numerically; codes, ranges, fractional inches and mixed units remain text order unless an explicit normalized numeric sort value is supplied.
