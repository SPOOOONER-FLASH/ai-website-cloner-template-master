## 步骤

1. 用浏览器打开 https://gitlab.com/cantonlock-hyde-group/CANTONLOCK-HYDE-project 并登录（就是服务器拉取的那个项目）。
2. 左侧菜单：**Settings（设置）→ Repository（仓库）**。
3. 找到 **Deploy keys（部署密钥）**，点右边的 **Expand（展开）**，再点 **Add new key（添加新密钥）**。
4. 填写：
   - **Title（标题）**：`86132-release`
   - **Key（密钥）**：把上面那一整行从 `ssh-ed25519` 到 `(write deploy key)` 复制进去
   - **Grant write permissions to this key（授予写权限）**：**必须勾上**。不勾，我就推不上去。
   - Expiration date（过期日期）：留空
5. 点 **Add key（添加密钥）**。

## 成功是什么样子

Deploy keys 列表里出现 `86132-release`，旁边标有「Write access allowed（允许写入）」。

## 如果找不到这些按钮

- 左侧菜单里没有 Settings：你当前登录的账号不是这个项目的 Maintainer 或 Owner。换成建项目的那个账号。
- 粘贴后报 "Key is invalid"：复制时少了开头或结尾。整行重新复制一次，`ssh-ed25519` 开头、`(write deploy key)` 结尾，中间不要换行。
- 其他情况：截图发我，先别动别的设置。
