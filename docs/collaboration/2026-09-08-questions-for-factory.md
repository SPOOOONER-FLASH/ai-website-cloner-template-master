## 一、DS011 到底是门吸还是插销？

| | |
|---|---|
| 目录里的名字 | `Door Flush Bolt`（插销） |
| URL | `/products/hardware-accessories/ds011-door-flush-bolt/` |
| 同前缀的另外 7 条 | 全部叫 `Door Stopper`（门吸） |
| 规格 | 只有「Material=Brass」加一串表面代码，**没有尺寸** |

**反向证据**：Bing 2026-09-08 关键词报告里有一条真实买家搜索 ——
`door stopper ds013 vs ds011`，把 DS011 当门吸和 DS013 比较。

没有改。前缀和搜索词都不足以判定一个产品是什么，改错了就是买家订到装不上的东西。
`src/data/product-naming.test.ts` 里有一条显式待办把它记着，工厂答复后删掉那一行、
改名字并加 301。

## 二、BS 和 SB 是同一个表面的两个代码

- `SB: "Satin Brass"` —— 目录既有的商品名表
- `BS` —— 甲方 2026-09-08 确认「satin brass, 铜砂光」，九月的产品文件夹也用这个拼法

两个都已收进 `src/lib/configurator.ts`，因为挑一个当正确的会让另一个在配置器里显示成
裸代码。**要不要让工厂退掉其中一个，是工厂的决定。**
