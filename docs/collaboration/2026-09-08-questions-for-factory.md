## 一、尺寸线图：能画的已经画了，剩下的缺数字

甲方 2026-09-08 提到「可以自己画点 CAD 上去」。**画不了，缺的不是工具是数字。**

`scripts/build-dimension-drawings.mjs` 已经在跑，出了 79 张 1:1 的尺寸线图 ——
但它只对**目录里已发布尺寸**的产品出图，没有数字就返回 null 不画。

一张线图上的每条尺寸线都会被买家当作可下单的依据。凭外观估出来的中心距、
backset 或孔位，画得越好看越危险：买家照着订，metal 到手装不上，一个柜的损失。
这跟拒绝替 MB / CP / BS 猜表面名是同一条规矩。

**需要什么才能画**：每个型号给到中心距、backset、面板长宽、孔位。给了就跑
`npm run assets:drawings`，当天出图。

优先级最高的是这 12 个刚补上照片但规格全空的：
`5687`、`5834`、`L002`、`L008`、`L009`、`L010`、`L016`、`L019`、`L023`、
`L024`、`L025`、`L026`。

## 二、（原一）DS011 到底是门吸还是插销？— 已答复，见上

| | |
|---|---|
| 目录里的名字 | `Door Flush Bolt`（插销） |
| URL | `/products/hardware-accessories/ds011-door-flush-bolt/` |
| 同前缀的另外 7 条 | 全部叫 `Door Stopper`（门吸） |
| 规格 | 只有「Material=Brass」加一串表面代码，**没有尺寸** |

**反向证据**：Bing 2026-09-08 关键词报告里有一条真实买家搜索 ——
`door stopper ds013 vs ds011`，把 DS011 当门吸和 DS013 比较。

没有改。前缀和搜索词都不足以判定一个产品是什么，改错了就是买家订到装不上的东西。
`src/data/product-naming.test.ts` 里有一条显式待办把它记着，工厂答复后删掉那一行、
改名字并加 301。
