# FSB 配置器与视频：HYDE 要不要做、怎么做（2026-09-29）

## 结论

1. **FSB 那种"一个产品实时换配置、换渲染"的完整版，现在不做。** 它的前提是每个组合都有工厂 CAD，我们一个都没有。按 AGENTS.md 的规则，没有 CAD 就只能"想象"金属件，这正是甲方明确禁止的。
2. **中间一步已经做成原型，零工厂成本：** 专属配置页 `/configurator/studio/`，FSB 的布局和切换动画，但舞台上每一张图都是所选型号本身的真实照片。同时产品页加了"表面处理 / 功能"切换。草稿 PR 待审。
3. **FSB 的视频可以用 HYDE 产品做同款，但必须先拿到一个型号的工厂 CAD（STEP 文件）。** 没有 CAD 时，替代方案是真实产品的微距实拍，节奏和片尾照 FSB 做。

## FSB 做了什么

| 项 | FSB | HYDE 现状 |
|---|---|---|
| 布局 | 左侧大舞台放产品，右侧分步卡片，顶部卡片显示货号、进度（如 4/9）、购买按钮 | 已有引导式配置器，但是"逐题缩小目录"，不是"一个产品换配置" |
| 配置项 | 9 步：轴承技术、套装类型、钥匙孔、安装方式、把手型号、门厚、方向、材质、表面处理 | 能干净拆出的只有 2 个轴：表面处理、功能（来自订货码语法 `587 PBET` = 587 · 抛光铜 · 入户） |
| 渲染 | 用 CAD 按组合出图，未选的货号位显示灰色 | 没有 CAD；站上仅 3 个按目录尺寸搭的外形模型（9004S、LC04、70SN），边角半径和孔位都没画 |
| 视频 | FSB 1138（拉姆斯设计）40 秒 CAD 微距渲染：镜头慢速掠过弧面和磨砂质感，灰背景，片尾 logo + 型号 + 色名 | 无 |

## 数据缺口（2026-09-29 实测，HYDE 已发布 549 个产品）

| 指标 | 数量 | 对配置器意味着什么 |
|---|---|---|
| 订货码能干净拆成"系列 + 表面处理 + 功能"的系列 | 35 个系列，117 个型号 | 这就是原型现在覆盖的范围 |
| 标了 2 种以上表面处理的产品 | 153 | 但每个只有一种表面处理的照片，其余不能上舞台 |
| 表面处理字段的不同写法 | 91 种（`Satin stainless` / `Satin Stainless` / `PB.AB.AC.CP.SN` / `All Available`） | 要先规范成代码表 |
| 有孔距 / 方轴 / 玫瑰尺寸数据的 | 46 / 44 / 20 | FSB 式的"门厚、方轴、钥匙孔"步骤无从谈起 |
| 有兼容关系（哪个把手配哪个锁体）的 | 27 | 做不了"套装"配置 |

## 三档方案

| 档 | 内容 | 需要工厂提供 | 我方工作量 |
|---|---|---|---|
| A 现在（已做原型） | 专属配置页 + 产品页切换，真实照片交叉淡入，订货码逐段生成 | 无 | 已完成，待你审 |
| B 中期（推荐下一步） | 给已有系列补拍每种表面处理的照片（同机位同光），并把 91 种表面处理写法规范成代码表 → 覆盖面从 35 个系列往上扩 | 每个系列每种表面处理一张标准照片；确认表面处理代码 | 数据规范 1–2 天；补图到位后页面自动覆盖 |
| C 完整 FSB 版 | 3D 实时换材质，或按组合预渲染图；加门厚、钥匙孔、玫瑰等步骤 | 每个型号的 STEP/CAD；兼容规则表；孔距、方轴、门厚范围 | 每个系列建模 + 材质 1–2 天，另加兼容规则数据；数周，前提是 CAD |

**建议：** 先上线 A；向工厂要两样东西——主推系列的全表面处理照片（推动 B），以及 1–2 个主推型号的 STEP 文件（例如 9004S 执手、587 球锁），用来验证 C 和做视频。开模时 CAD 一定存在，问题只是工厂愿不愿意给。

## 视频

- FSB 视频是 CAD 渲染，靠的是精确的弧面和表面质感。我们按目录尺寸只能搭出方块外形（见 `docs/design-references/2026-09-07-home-stills/models-9004s/9004s-preview.png`），做成微距视频会直接暴露"不是真的"。
- **有 STEP 文件后：** 用 Blender 做同款——慢速微距掠过、灰背景、片尾 HYDE logo + 型号 + 表面处理名。一个型号约 1–2 天。
- **没有 CAD 时：** 真实产品微距实拍（转台 + 滑轨，灰背景，同样节奏和片尾卡），半天拍摄即可，完全符合"不想象产品"的规则。

- 新页面：`/configurator/studio/`，仅英文，暂设 noindex，不进导航，等你认可后再加 9 个语言、进 sitemap。
- 左侧舞台吸顶，切换时新旧照片交叉淡入（0.56 秒），右侧：订货码卡片（未确认的段落是灰色，确认后变黑并有入场动画）、进度条、报价按钮、产品页链接；下面是"系列类别 → 型号 → 表面处理 → 功能"四步卡片。
