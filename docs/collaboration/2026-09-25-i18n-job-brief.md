# 翻译作业说明（给子代理）：术语表与界面文案

> 通用规则在 `docs/collaboration/2026-09-24-market-locale-brief.md`（十条写作规则、各语种变体与行业叫法）。
> 本文件只说**作业文件怎么填、怎么校验**。

## 作业文件

`tmp/i18n/<locale>-<kind>[-<section>]-<index>.json`：

```json
{ "locale": "de", "kind": "glossary", "section": "specValues", "index": 1,
  "items": [ { "key": "Wall-mount", "section": "specValues", "source": "Wall-mount", "reference_es": "Montaje en pared", "target": "" } ] }
```

- 只填 `target`，其他键不动，条目顺序不动，不增删条目。
- `reference_es` 是西语译法，**只做上下文参考**（例如判断一个词在本站的含义），不要从西语转译；目标语言按英文源写。
- `kind: "ui"` 的 `source` 是界面句子，`where` 告诉你它出现在哪个组件，方便判断语境（按钮、标题、表头、正文）。

## 每类的规则

| kind / section | 是什么 | 怎么翻 |
|---|---|---|
| glossary / specLabels | 规格表的**行标签**（Backset、Door thickness、Cycle life） | 本语种五金行业规格表里的标准叫法；简短，名词短语，首字母按本语种惯例 |
| glossary / specValues | 规格表的**值**（Stainless steel 304、Left hand、Entrance function） | 材质、功能、门型、包装术语按行业叫法；**数字、单位、型号、标准号原样保留**（60 mm、EN 1125、SS304）；`A / B` 这种组合值分别翻并保留分隔符 |
| glossary / finishNames | 表面处理名（Satin Stainless Steel、Polished Brass） | 行业叫法；括号里的代码（SSS、PB）如在源里出现则原样保留 |
| glossary / materialNames | 材料名 | 行业叫法 |
| glossary / categoryNames | 品类与子类名 | 与已有 `content/i18n/<code>/categories.json` 里的名字**一致**（先读它） |
| glossary / productNames | 产品通用名（Panic Exit Device Trim、Tubular Lever Handle） | 产品页标题用词；名词短语；不要加型号 |
| glossary / terms | **行业核心词**（Ironmongery、Custom/Customize、Bespoke）：甲方 09-25 定为核心词，已按各语种行话填好；**文章、界面、产品文案里凡出现这些概念，用 `terms` 里的说法**，不要另造 | 与 `content/i18n/<code>/glossary.json` 的 `terms` 一致 |
| ui | 界面与页面文案 | 按语境：按钮用祈使/名词短语，标题给判断，正文自然；`{count}`、`{name}` 等占位符**原样保留**；`—` 破折号可换成本语种标点；网站名、HYDE、Canton Hyland 不翻 |

## 校验与合并

填完一个文件就跑：

```bash
node scripts/i18n-merge.mjs tmp/i18n/<file>.json
```

它会拒绝：空译文、与英文相同的译文、丢失的型号/标准号/占位符、非日语里的汉字、日语里 7 连汉字、东方阿拉伯数字、bidi 控制符。
被拒的条目会逐条打印原因；改好后重跑同一条命令即可（已合并的条目不会重复）。**退出码 0 才算完成**。

## 语种要点（摘）

- de：Sie；复合词；千分位点；DIN/EN 叫法（Dornmaß、Entfernung、Einsteckschloss、Drücker、Profilzylinder、Türschließer、Band、Schließblech）。
- fr：vous；法式标点（`:` `;` `!` `?` 前窄不换行空格 U+202F）；axe（backset）、entraxe、béquille、serrure à mortaiser、ferme-porte、paumelle、gâche。
- ja：です・ます体；全角标点；バックセット、芯々距離、箱錠、レバーハンドル、シリンダー、ドアクローザー、丁番、ストライク；**不写 7 个以上连续汉字**。
- ko：합니다체；谚文；백셋、센터 거리、모티스 락、레버 핸들、실린더、도어 클로저、경첩、스트라이크。
- tr：siz；千分位点；backset（保留）、aks mesafesi、gömme kilit、kapı kolu、silindir、karşılık、kapı kapatıcı、menteşe。
- ru：Вы/вы；«ёлочки»；бэксет、межосевое расстояние、врезной замок、нажимная ручка、цилиндровый механизм、ответная планка、доводчик、петля。
- ar：现代标准阿拉伯语；**西式数字**；型号不镜像；مسافة الظهر / الباك سيت、المسافة بين المحورين、قفل غاطس、مقبض ذراع、أسطوانة، صفيحة الإغلاق، غلاق الباب، مفصلة。
