## 一、五种「一套」的组合逻辑

这是这行的常识，也是 Yale 和 Assa Abloy 的产品页在做的事：**按门的类型分套，
不按零件分类。** 一扇门要装什么，就是一套。

### 套 A — 插芯锁门（欧规，工程/公寓门）

```
锁体（LC 系列）  +  欧规锁芯（70mm 等）  +  执手连板（6068 等）  ＋ 锁片
```

三件缺一不可，而且三件在我们目录里分属三个类目 —— 买家要点三次才凑齐。
**这是最该拍成组合的一套**，也是 Yale 官网的主力呈现方式。

> 配套关系：**部分确认（甲方 2026-09-09）** ——「LC 锁体配 072 逃生锁，
> 072 防火锁体有两个葫芦孔的。」
>
> 这把 A 套和 B 套接上了：LC 系列锁体就是逃生推杠那一侧的锁体，307 页面上写的
> `Lock Case: 072` 指的是它。**还缺两件**才能开拍：(1) 42 个 LC 型号里具体哪些配 072；
> (2) **072 在目录里没有产品记录** —— 见下面第零节之二。

### 套 B — 逃生推杠门（消防/公共建筑）

```
推杠（307 / 305 / 310）  +  外执手（035 或 9080E）  +  锁芯  ＋ 锁盒 072
```

**唯一已确认的一套** —— 307 的规格行里就写着。307 是询盘第一的产品，
这一套的场景图价值最高。

> 配套关系：**已确认**（307 → 015 / 9080E / 072）。305 与 310 待确认。

### 套 C — 管状/筒式锁（住宅门，本身就是一套）

```
607 / 587 / 578 —— 出厂即含执手、锁芯、锁舌、锁片
```

**不要拆开拍。** 它本来就是一套，拆开摆反而看不出是什么。
适合拍「拆解平铺」：执手、玫瑰盖、方轴、锁舌、锁片、螺丝一字排开。

> 配套关系：**产品自带**，无需确认。

### 套 D — 附加锁 / 夜锁（旧门加装、英式门）

```
564 夜锁本体  +  锁盒  +  钥匙
```

单件成套。564 的转化率是全表最高（28.57%），且已有尺寸线图。

> 配套关系：**产品自带**。

### 套 E — 玻璃门（无框玻璃门）

```
夹具（F 系列）  +  地弹簧 / 转轴  +  拉手  +  锁夹
```

四件配套，且都在 `glass-door-accessories`。

> 配套关系：**待工厂确认**。

## 三、什么一起拍，什么分开拍

| 情况 | 怎么拍 | 为什么 |
|---|---|---|
| **锁体 + 锁芯 + 执手** | **一起** | 一扇门装的是这三件，分开拍买家要点三次才知道要买什么 |
| **推杠 + 外执手 + 锁芯** | **一起** | 307 的规格行已经这么写了，图要和文字一致 |
| **管状锁 / 球形锁** | **单独，拆解平铺** | 它本来就是一套，再加别的零件反而混淆 |
| **夜锁 564** | **单独** | 单件成套 |
| **同一型号的不同表面** | **一起，同一角度并排** | 这是「一致性即论据」——四个表面同角度并排说明有工艺流程 |
| **不同类目的零件** | **分开** | 除非它们真的配成一套。合页和锁芯放一起没有任何道理 |
| **重工业件 + 轻五金** | **绝不同框** | 我们是小五金厂，混拍读作图库拼凑 |

## 四、三条硬约束（`AGENTS.md` 已写死）

1. **不生成任何想象出来的金属产品。** 孔位、螺距、方轴、中心距在开模前就定死了，
   生成的执手是装不上的零件，而买家认得出型号。
2. **不混搭不成套的零件。** 「组装一个工厂并不成套出售的 set」是明令禁止的。
   所以第一梯队每一组都要先确认配套关系。
3. **一张图里表面处理必须一致。** 客户订黑色，图里每一件都得是黑色。

## 五、参考对象怎么做的

甲方点名 [shopyalehome.com](https://shopyalehome.com/) 与
[assaabloy.com](https://www.assaabloy.com/group/en)。这两家的共同点：

- **按门分套，不按零件分类** — 首屏问的是「你要装哪种门」
- **场景克制** — 一面墙、一扇门、一束侧光，没有道具堆砌
- **配套关系写在页面上** — 图里为什么是这三件，文字里能查到

第三条是我们目前最大的差距，而它不是作图能补的。
