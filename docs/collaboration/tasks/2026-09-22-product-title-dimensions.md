## 关键设计决定：尺寸必须带标签

第一版方案是直接把尺寸接在标题后面。样例立刻暴露问题：

```
015 Panic Exit Device — ABS, Up to 80mm      ← 80mm 是门厚，不是设备尺寸
1073D Night Latch And Rim Lock, 60mm         ← 60mm 是 backset，标题没说
```

**不带标签的尺寸有歧义**，买家会读成锁体尺寸。按 AGENTS.md 的规矩，
「一个看似合理的数字代价是一个货柜」—— 有歧义的数字比没有数字更糟。

所以每个尺寸按来源字段带标签：

| 来源字段 | 标题里写成 | 命中数 |
|---|---|---|
| Size | 原值 | 69 |
| Overall length | `900mm` | 143 |
| Length | `600mm` | 39 |
| Plate length | `300mm plate` | 1 |
| Backset | `60mm backset` | 109 |
| Door thickness | `for 35–55mm doors` | 66 |

## 超长时的取舍：舍材质，保尺寸

191 条加了标签会超 60 字符，几乎全因材质串太长（`Zinc Alloy+Brass`、
`304 Stainless Steel`）。取舍规则是**舍材质**，理由不是长度而是可得性：

- **材质在页面规格表里一定看得到**（325 个产品有 Finish 行，Material 更普遍）
- **尺寸往往看不到** —— 924 个产品里只有 497 个发布了任何一个可用尺寸

对一个搜型号的人来说，尺寸确认「是不是我要的那个零件」，材质是次要的。

```
028 Panic Exit Device — Zinc Alloy+Brass, for 55mm doors | Canton Hyland  (72)
→ 028 Panic Exit Device — for 55mm doors | Canton Hyland                  (54)
```

**品牌后缀 `| Canton Hyland` 保留。** Bing 数据显示品牌词点击率 26%、
「+联系方式」66.67%，品牌实体识别正在起作用，不能为了省 15 个字符砍掉它。
