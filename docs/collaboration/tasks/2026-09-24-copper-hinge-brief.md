# copper hinge：让搜「copper」的买家落到黄铜合页（2026-09-24）

甲方微信（09-24）：客户问的是黄铜 brass，不是纯铜 copper；但很多国家把 brass hinge 叫 copper hinge，叫法不同。
纯铜太软，不能做承重合页，所有合页都是黄铜（铜锌合金）或其他合金。

## 指南要点（文案会话）

- 纯铜软，不承重；行业说的 copper hinge 是黄铜（铜 + 锌）。
- 「仿古铜 antique copper（AC）」只是表面处理颜色，不是材质。
- 沿海和潮湿环境：黄铜脱锌问题，链接现有 guides/brass-alloys-and-dezincification-2026。
- 可引用的 HYDE 事实：材质确为黄铜的合页只有 B024、B025。
- 不要引用「Brass Piano Hinge」：记录材质写 Iron，与名字矛盾，已报工程会话问工厂。
