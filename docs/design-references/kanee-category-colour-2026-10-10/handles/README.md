# Handle and cylinder photographic studies

Selected outputs and current PREVIEW/HELD decisions are in ../selection.json and
../review.json. Sources, masks, receipts and experimental outputs are retained.
Do not automatically publish every generated file.

recipe.mjs rebuilds the initial handle/knob/deadbolt studies. The selected oval
cylinder is the separate repair-oval-ground.mjs result, not its initial white-island
draft. That repair uses a manually traced genuine photographic silhouette and the
same source photograph's ground luminance. It never invents product RGB or shadow.
Retained opaque RGB is asserted against the source; contour completeness is a
separate visual check. Final factory model/finish/supply-kit approval remains open.
