# HYDE 彩色真实产品摄影评审包

更新：2026-10-12。17 个类目，每类目标两款不同产品；本包已有 **33 款草稿**。
其中 **21 款可评颜色与构图（PREVIEW）、12 款待修（HELD）、1 个位置缺合适来源**。
这不是34张完稿，也不是工厂确认或客户审美验收。未替换任何线上产品图片。

## 看图

- 打开 index.html：先看21张可评审图，待修图在折叠区。
- overview/selected-six.jpg：6张选览；型号只标在图外。
- selection.json：17×2的型号和主图清单；不同颜色或视角不重复计数。
- review.json：当前逐图判断的唯一权威，覆盖子目录旧状态。
- inventory.json：生成的尺寸、文件位置、主图SHA256和状态。

松绿、陶土、深蓝、酒红四套空摄影场来自图像生成工具；
提示词和背景哈希保存在 empty-fields/prompts.json。
金属产品来自仓库真实上传照片，不是文生产品或三维模型。
PNG是无损检查主图；WebP是方便调用的伴随文件。

## 使用界限

只允许评审，不自动进入正式产品宣传。保留孔位、钥匙、螺纹、零件及原片镀色。
不透明保留区RGB核对只能检查像素处理，不能证明蒙版完整、照片型号正确、
珠数、材质、承重或实际供货清单。半透明边缘去白会改变边缘RGB，均须另行目视复核。

564 MB、椭圆锁胆等有对应原片地面明暗，采用真实源阴影。
其余多为目录产品肖像，不凭空补落地阴影，不冒充实拍接触面。
椭圆锁胆与葫芦型分别选材；不能根据外露圆点推定内部珠数。

12张HELD的原因见review.json：白底残留、镜面高光与背景难分或轮廓细边。
缺位是第二款地弹簧/门轴：现有D系列记录为RAYEN-only，不偷换品牌归属，
也不把F100的第二视图计成另一个型号。
301的图文表面处理以及5836的钥匙数/厚度记录有矛盾，未修改或补造规格。

## 复现与校验

在保留完整仓库的当前评审分支运行各子目录recipe.mjs（原片与背景保留在包内）。
椭圆锁胆另用 handles/repair-oval-ground.mjs；旧白底版本保留作诊断，不使用。
最后运行：

    node docs/design-references/kanee-category-colour-2026-10-10/build-overview.mjs

此命令断言17类×2位置、34个不同型号标识、文件存在和已锁定的审图哈希，
生成本地画廊、联系表及inventory.json。产品生成器另有原片哈希和保留区RGB断言。
人工描边并不等于工厂认可；后续每张修图须重新检查原片与型号。
