# Homepage realism preview — 2026-09-02

This folder is a **review set, not a live-site asset folder**. None of these images may be
copied into `public/images/` or referenced from the homepage until the client chooses a
direction and the product relationship has been checked against source photography.

## Non-negotiable review rules

1. One image makes one claim. Do not mix unrelated hardware to imply a kit.
2. A kit uses one finish family: all black, all satin stainless, or another confirmed finish.
3. Product geometry comes from a real catalogue photograph. No invented holes, fasteners,
   backplates, latch relationships, door-edge relationships, or mirrored operating parts.
4. A door application must respect inside/outside faces and installation height.
5. Heavy workshop equipment and concealed overhead closers do not belong in a small-hardware
   set photograph.
6. Real factory photography is evidence. Do not redraw workers, machines, lines, gauges, bins,
   products, or process steps merely to make a cleaner picture.
7. Old oval Hyland marks must be removed by reconstructing the local surface; a white patch,
   residual crescent, registered mark, or covered product is a rejection.
8. AI-assisted product images are editorial candidates, never specification or certification
   evidence. The source photograph remains authoritative.

## Rejected during this batch

An AI-cleaned assembly-line attempt was rejected because it redrew bins, robots, labels and
production-line details. It looked more polished but became weaker evidence. The authentic
`09-real-assembly-line.webp` replaces it.

The first fire-exit concept was also rejected because it paired a satin-silver 305 with a black
016 trim. The retained candidate uses the 305's source-confirmed powder-coated black option so
the visible set follows the client's one-finish rule.
