## 二、设计语言：七条可以直接抄的规则

1. **一页一个产品。** 整页只讲 1138，所有区块都在回答「为什么这一支值得买」。
2. **全页只有一个会动的东西。** 「会动」的只有英雄区那支片子，其余全部静止；没有滚动动画、没有视差。
   动得少，动的那一处才显得贵。
3. **一张照片只讲一个细节，图注一句话。** 食指凹槽就是一张照片、一句话。不堆卖点。
4. **表面有代码也有名字。** rgs = rams grau schwarz；Aluminum Pure；「black bead-blasted anodized aluminum」
   —— 每个表面是一个完整的工艺描述，不是「黑色」。
5. **款式网格靠一致性说话。** 8 张同光、同角度、同背景、同比例。一致本身就是「这是一家有流程的工厂」。
   （和 AGENTS.md「Consistency IS the argument」同一条。）
6. **卖的是看不见的工程。** 材料、轴承、不下垂、可回收——都是可验证的事实，没有形容词堆砌。
7. **结尾是一个真人。** 不是表单，是有名字、有照片的人。

## 三、为什么 ONE TAKE 只有执手能用

FSB 的特写之所以好看，是因为镜头推到哪里都有**设计过的细节**（食指凹槽、圆颈），而这些细节在 CAD 里是完整的。

我们的尺寸图对不同品类定义到的程度差别很大：

| 品类 | 尺寸图定义了什么 | 结果 |
|---|---|---|
| 执手 9014 / 9004S / 玻璃门拉手 | 长度、伸出、管径、面座、拐角——**看得见的每个面都有尺寸** | 模型就是产品本身，特写经得起看 |
| 锁体、合页、门吸、逃生推杠、外侧执手 | 只有外轮廓；舌栓位置、孔位、叶片截面、端盖都没发布 | 按规矩只能省略 → 特写里是一个光滑的盒子 |

**规则（以后做片子先过这一条）：尺寸图能定义画面里每一个看得见的面，才做一镜到底特写；只能定义外轮廓的，
不做特写，只用实拍。** 这条已写入 ONE TAKE 的 README。

## 四、HYDE 怎么照做：9014 执手专题页（建议）

9014 天然对得上 1138 的结构：一个执手，三个功能款（通用 / SSET 入户带锁 / SSBK 卫浴），一张完整尺寸图，
每款都有工厂实拍视频（`public/videos/products/9014-sset-…mp4`、`9014-ssbk-…mp4`）。

| FSB 区块 | HYDE 9014 版 | 素材现状 |
|---|---|---|
| 英雄片 | ONE TAKE 9014（12 秒，无声，循环） | 有（720p；4K 等 johns 机器） |
| 导语 | 135 / 60 / Ø19、面座 Ø53×9、不锈钢、US32D 拉丝、中山工厂、门厚 35–50 | 记录里全有 |
| 细节照 ×3 | 45° 斜接、面座边、拉丝纹理 | **缺真样品微距照**。临时可用片中截帧（按图纸建模，不是想象），但真照片更好 |
| 引语 | 不编。用工厂一句真话，或直接省掉这一块 | 需甲方给 |
| 看不见的工程 | 只写记录里有的事实（材料、门厚范围、锁芯）；没有的（回弹弹簧、盐雾小时数）不写 | 部分有 |
| 可选款式 | 9014 / 9014-SSET / 9014-SSBK 三格，**同一拍法重新整理**（灰场、同角度、同比例） | 实拍有，风格不统一；Codex 可按「清理真实照片」规则统一 |
| 尺寸图 | 代替 FSB 的手册缩略图，外加规格 PDF | 有 |
| 真人联系 | Johnson Liu（作者页已有十语种） | 有，缺正式头像 |

**需要工厂补的只有一样：每支主推执手 3 张微距实拍**（斜接拐角、面座边缘、拉丝方向），手机 + 灯箱即可，
灰背景。有了这 3 张，这一页就和 FSB 同一个段位；以后每个有完整图纸的执手都复用同一模板。

## 五、不照搬的地方

- FSB 有设计师故事（Rams、1986）。我们没有，就不编；用「工厂 + 尺寸 + 一致性」替代「设计师 + 年份」。
- FSB 的款式图是纯白底。我们站内产品图统一的是共同地平线标准（`npm run audit:productimages`），专题页沿用站内标准，不另起一套。
