# FSB 1138 英雄视频逆向 → HYDE 9014 第一版（2026-09-29）

甲方 09-29 发来 FSB 产品配置器页面和 FSB × Dieter Rams 英雄视频，问两件事：能不能用 HYDE 产品逆向做一支；配置器要不要升级。

## 一、FSB 视频拆解（参考片，不进任何公开资源）

1280×720，30 fps，40.0 秒，无声，**一镜到底，没有剪辑点**。不是实拍，是 3D 渲染（CAD 模型 + 物理材质 + 虚拟摄影机）。

| 时间 | 机位 / 运动 | 画面 |
|---|---|---|
| 0–4 s | 与执手侧面几乎平行，贴着表面低角度 | 执手只剩一条剖面剪影，上半部浅灰渐变背景 |
| 4–10 s | 摄影机慢慢抬高、横移 | 露出握持凹槽的圆角，高光沿边缘滑动 |
| 10–15 s | 转到下方，材质压到近黑 | 凹槽与边缘的反光带是唯一的信息 |
| 15–20 s | 回到正面，微距 | 粉末涂层的颗粒质感清晰可见 |
| 20–34 s | 同样的轨迹再走一遍（下半段反向） | 形成闭环 |
| 34–40 s | 回到开头的侧面剪影 | 落版在执手平面上浮出：`└ FSB` │ **FSB 1138** / 1986 \| 2026 │ **rgs** / rams grau schwarz |

要点：
- 单一主体、单一镜头、单一材质、几乎单色。信息全靠**掠射光在曲面上的高光**。
- 首尾画面相同（首帧与末帧平均像素差 4.8/255），可以无缝循环当英雄区背景。
- 落版语法：品牌标 │ 型号 + 年份 │ 表面代码 + 表面名称。字小，放在产品本身上，不喧宾夺主。

## 二、为什么不用照片做

09-07 甲方已否掉「对照片做推拉缩放」的做法（见 `2026-09-07-hyde-motion/BRIEF.md`），原因正确：照片没有第三维，摄影机不能绕过去，掠射高光也不会跟着动。FSB 的效果只能来自三维模型。

而 AGENTS.md 禁止想象产品。所以唯一合规路径是：**只用工厂发布的尺寸建模**。

## 三、HYDE 版：9014 不锈钢执手

选 9014 的理由：它的主图就是工厂尺寸图（`public/images/products-hyde/9014-stainless-steel-handle.webp`），而且几何简单到图纸就能完整定义：

| 尺寸 | 值 | 来源 |
|---|---|---|
| 执手长 | 135 mm（外沿） | 9014 尺寸图 / `content/products/9014-stainless-steel-handle.json` |
| 伸出 | 60 mm（面座外面到执手外沿） | 同上 |
| 管径 | Ø19 mm | 同上 |
| 面座 | Ø53 × 9 mm | 同上 |
| 拐角 | 45° 斜接（直角 L） | 尺寸图画法 + 实拍 `9014-sset-stainless-steel-handle.webp` |

**省略**（没有尺寸就不画）：紧定螺丝、面座边缘造型、焊缝、方轴、锁芯盖。
**中性处理**：所有棱边 0.5 mm 倒角，只为让高光能显出边缘，不是产品特征。
**表面**：拉丝不锈钢（SSS / US32D），拉丝方向沿管轴。

### HYDE 版镜头表（24 fps，18 秒，432 帧）

| 时间 | 机位 | 画面 |
|---|---|---|
| 0–4.5 s | 低位、正前方，对着执手端头 | 管端和拉丝管身，面座在远处虚焦 |
| 4.5–8.5 s | 沿管身横移 | 高光沿管身滑动 |
| 8.5–12.5 s | 抬高越过斜接拐角 | 45° 斜接是这支执手唯一的「设计」，给它最长的时间 |
| 12.5–15.5 s | 绕到侧面，沿颈部下到面座 | 颈部与面座的关系 |
| 15.5–18 s | 拉远到 3/4 全景并停住 | 全貌；14.2 s 起落版淡入：HYDE 标 │ **9014** / 135 · 60 · Ø19 mm │ **SSS** / satin stainless steel |

落版把 FSB 的「年份」换成了**三个尺寸**：对进口商来说，尺寸就是信任（AGENTS.md「专业不装饰」）。

## 四、对得上 FSB 的，和对不上的

| 已做到 | 做不到 / 需要什么 |
|---|---|
| 一镜到底、微距、掠射高光、慢节奏 | **成片画质**：现在 12 采样 720p。johns 机器 4090 上跑 4K、256 采样即可到 FSB 水平，同一个脚本改参数 |
| 灰色渐变背景、近单色 | **拉丝纹理的真实感**：现在是程序纹理。要一张真样品的微距照片（或一块样品）做材质参考 |
| 落版语法（标 │ 型号 │ 表面） | **完整细节**：紧定螺丝、焊缝、面座倒边——需要工厂的 CAD（STEP/IGES）或带这些尺寸的图纸 |
| 几何 100% 来自工厂图纸 | **首尾无缝循环**：现在是 18 秒单程；做成循环要再设计一段回程，40 秒 |

**关键建议**：工厂开模时一定有 CAD。拿到一支执手的 STEP 文件，就能做出和 FSB 同级的片子，而且每个有 CAD 的型号都能批量复用这条管线（换模型、换表面、改落版文字）。

## 五、配置器：要不要做成 FSB 那样

**结论：不照搬 FSB 的 3D 配置器；在现有向导旁边加一个「执手套装配置」模式，先从 9014 这类有图纸的执手开始。**

- FSB 的配置器是**一个型号的变体**（面座形状、锁孔、表面、方轴、门厚），每个组合都有渲染图，因为它卖给建筑师单套配置。我们现有的配置器是**从 590 个型号里筛选**，服务进口商按型号下单。两者解决的问题不同，现有的不该被替换。
- 做 FSB 式实时渲染的前提是**每个部件都有 CAD**。没有 CAD 就只能想象，违反 AGENTS.md 铁律。
- 值得做的升级：执手 → 面座（圆 / 方）→ 锁孔盖（PZ / BB / WC / 无）→ 表面 → 门厚 → 功能，状态写在网址里，结尾生成**规格行 + 询盘预填 + PDF 规格单**。画面只显示真实存在的组合（照片或按图纸建的模型）。
- 顺序：先拿到 3–5 个畅销执手的 CAD → 用本管线出模型 → 再做配置器界面。先做界面、后补模型会变成空壳。
