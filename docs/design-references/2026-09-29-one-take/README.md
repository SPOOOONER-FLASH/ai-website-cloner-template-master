# HYDE · ONE TAKE — 十支一镜到底产品片（2026-09-29）

甲方 09-29：在 FSB 仿制片的基础上「取个名字，做十个，选不同颜色，黑色逃生锁打头，
十个独立 mp4，像做作品集」。

**名字：ONE TAKE（一镜）。** 每支 12 秒、24 fps、1280×720、无声、一镜到底：
低角度贴着产品最长的一条边进（掠射光）→ 沿着它走 → 抬过这个产品唯一的「设计点」→
绕到背面看它怎么装在门上 → 拉远停住，落版淡入（HYDE 标 │ 型号 + 三个尺寸 │ 表面代码 + 表面名）。
十支用同一套灯（一条顶光带、一条背光带、一块柔光）、同一个渐变场、同一种落版，
按产品尺寸自动缩放，所以并排放时是「同一家工厂拍的」。

## 铁律：只用发布过的尺寸建模

`AGENTS.md`「Never generate an imagined metal product」。每个模型的几何只来自产品记录
（`content/products/<slug>.json`）或图库里的工厂图纸；没有尺寸的部件**省略**（孔位、螺丝、
钥匙孔、弹簧），需要闭合的地方用**记录在案的中性值**（让掠射光能读出棱边的 0.5 mm 倒角、
记录没给的板厚）。每支的说明写在 `scripts/blender/one-take.py` 对应 builder 的 docstring 里，
渲染时同时写进帧目录的 `lockup.json`。

## 复现

```bash
pip install bpy pillow numpy            # bpy = Blender 5.0 as a Python module；ffmpeg 在 PATH
python3 -c "import sys; sys.argv=['x','--','311','frames/311/f_','all','1.0','10']; exec(open('scripts/blender/one-take.py').read())"
python3 scripts/blender/one-take-composite.py frames/311 hyde-one-take-311.mp4 Archivo.ttf logo.png
```

云端 4 核 CPU：每帧约 5 秒，一支 288 帧约 25 分钟。johns 机器 4090 上把 `RES=3.0`（3840×2160）、
`SAMPLES=128` 即为成片级，脚本不用改。

## 和 FSB 还差什么

同 `../2026-09-29-fsb-film-reverse/BRIEF.md` 第四节：画质靠 4090 重渲；拉丝真实感要一张真样品微距照
做材质参考；细节完整度要工厂 CAD（STEP）。拿到任何一个型号的 STEP，就能把它替换进这条管线，
落版和镜头不用动。
