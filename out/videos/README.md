# 产品视频

自托管视频放这里，在 CMS 的产品「视频」字段里填 `/videos/文件名.mp4`。

## 什么时候放这里，什么时候用 YouTube

| | 自托管（放这个文件夹） | YouTube / Vimeo |
|---|---|---|
| 适合 | 30 秒以内的短片、开门演示 | 工厂参观、长片 |
| 体积 | **每一 MB 都会进 git 仓库，每次部署都推到服务器** | 不占我们的空间 |
| 第三方 | 无 | 有（已用 youtube-nocookie / Vimeo dnt=1，播放前不写标识） |

建议：**超过 20 MB 的一律传 YouTube**，在字段里直接粘视频链接就行，
系统会自动识别是链接还是本地文件，不需要你选。

## 格式

- MP4（H.264 + AAC）兼容性最好
- 建议 1920×1080 或 1280×720
- 一定要配封面图，否则播放前是一块黑方块，在产品页上看着像图裂了
