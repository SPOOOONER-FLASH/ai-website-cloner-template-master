카탈로그

17개 제품군. 한 곳의 공장.

아래 모든 모델은 샤오란 자체 공장에서 생산합니다. 레버, 락 케이스, 실린더를 함께 주문하면 같은 마감으로 도착하고 하나의 문 가공에 맞습니다. 모델 수는 직접 입력한 값이 아니라 빌드 때마다 카탈로그에서 집계합니다.

치수, 마감, 도면, 사진이 실린 제품 페이지 자체는 영문으로 제공됩니다. 모델 번호와 치수는 어느 언어에서나 같습니다.

영문 전체 카탈로그 열기재질, 문 종류, 규격으로 검색

제품군

  • 패닉 엑시트 디바이스

    피난 경로용 패닉바와 터치바입니다. 방화문용, 경보형, 양개문용, 수직 로드 세트를 갖추고 있으며 외부 트림을 함께 공급합니다.

    제품군 보기 · 25개 모델

  • 스테인리스 핸들

    로즈형과 플레이트형 스테인리스 레버 핸들입니다. 문 두께 35~50 mm용 9000 시리즈를 포함합니다.

  • 노브 락

  • 욕실 액세서리

    대부분 스테인리스 재질의 욕실 액세서리입니다. 문 철물과 같은 마감으로 공급합니다.
