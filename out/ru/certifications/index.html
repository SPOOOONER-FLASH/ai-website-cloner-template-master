Подтверждение качества

Сертификаты и протоколы испытаний. Что испытано и на чьё имя.

Записи ниже приведены с точным перечнем моделей, напечатанным в каждом документе, и протокол на одну модель никогда не выдаётся за подтверждение для другой. Значительная часть продукции для заказчиков private label сертифицируется на их собственное имя, по их запросу и за их счёт, поэтому этими сертификатами распоряжаются они. Испытания CE и ANSI на имя Canton Hyland по основным линейкам готовятся; каждый новый протокол появится здесь с указанием области действия по мере выдачи.

Органы, выдавшие протоколы, ограничивают их копирование, поэтому мы высылаем полную копию по запросу на конкретную модель, а не публикуем выдержки.
