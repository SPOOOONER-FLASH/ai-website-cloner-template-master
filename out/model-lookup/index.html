Reference

An old model number still means something here.

A quotation outlives the catalogue that produced it. If a number on an old schedule no longer finds a page, one of three things happened to it, and this page says which — 18 records were renamed, 67 are in the catalogue without a published photograph, and one category path was retired.

None of these is a discontinued product. Where a model does go out of production we will say so here, in those words, with the date.

Renamed records

The part did not change. Its name did, so that the name and the specification agree. Every old address below still resolves — it returns a permanent redirect to the page named beside it, so a link in an old email keeps working.
