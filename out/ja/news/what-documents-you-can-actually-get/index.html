カットシート、CAD、BIM：当社にあるもの、ないもの

カットシート、DWG、BIMオブジェクト、ficha técnicaを探してここにたどり着く方がいます。そのうちいくつかは現在掲載していて、いくつかはご要望に応じて送れ、1つはまだ存在しません。どれがどれかを示すほうが、何でも約束するダウンロードページより役に立ちます。

このサイトに届く検索語には、繰り返し現れる形があります。人々は製品ではなく、ファイルを探しているのです。錠のカットシート。DraftSightやDWGのモデル。ficha técnica付きのBIMオブジェクト。サンプルのPDF。ある例では、誰かが部品表の1行（図面番号、位置、材質、用途）をそのまま検索窓に貼り付けていました。購買担当の技術者が、図面を満たす部品を見つけようとするときにすることです。どれも根っこは同じ依頼です。自分の書類に入れられるものがほしい、ということです。

そこで、存在する量の多い順に、正直な在庫を示します。

寸法入りのSVG素材：カタログの588件の記録のうち、HYDEの型番スラッグについて84点です。そのうち72点は、購入者が閲覧できる写真付きの521件の製品掲載に表示されています。残りの12点は、掲載されていない記録に属します。図面は、公開している元データで裏付けられた寸法を示しています。製品の外観図であって、扉の加工用テンプレートではありません。推測した穴の位置は、信じられてしまうかもしれないので、図面がないより悪いのです。

仕様：すべての製品ページに、文章ではなく表として掲載しています。バックセット、芯々距離、材質、仕上げコード、試験済みのものは耐久回数、扉厚の範囲、勝手。値が欠けているところは欠けたままで、推定はしていません。ページではなく表計算のファイルで必要なら、お問い合わせください。お送りします。

カタログ：現行のPDFが1冊です。以前は2冊（デザインしたパンフレットと、自動生成した輸出用カタログ）ありましたが、2026年9月21日にパンフレットをダウンロードの一覧から取り下げました。残っている1冊はスキャンではなくテキストのPDFです。文字を選択・検索でき、つまり検索エンジンやAIアシスタントが読むことができます。掲載しているすべての型番を仕様表付きで収録し、シリーズごとのしおりと巻末の索引があり、見開き2ページで開きます。取り下げたパンフレットはスキャンで、機械から見れば1語も含んでいませんでした。

試験書類：ご要望に応じて、正確な適用範囲とともに提供します。各書類の事実（試験所、番号、発行日、対象の特定の型番）を掲載し、仕様上必要な場合は正規の経路で書類をお送りします。見出しより適用範囲の行が重要な理由については、別の記事があります。

次に、当社にないものです。BIMライブラリはありません。RevitファミリもIFCオブジェクトもありません。寸法入りの図面がある型番なら、仕様と一緒にモデル作成者のための元資料として提供できますが、その用途では形状と欠けている寸法を確認する必要があります。当社が掲載しているのはSVGの製品外観図で、単位と縮尺を確認すればCADに取り込めます。型番ごとのネイティブのDWGライブラリは管理していません。

承認図書をまとめる方への実務上の注意が2つあります。1つ目に、書類は型番で、購入する構成（仕上げと機能の接尾辞を含む）で求めてください。バックセット60mm（2-3/8"）のタイプの図面は、45mm（1-3/4"）のタイプの図面ではないからです。2つ目に、書類を何に使うかを教えてください。施主承認用のカットシート、扉メーカーの加工段取り用の図面、入札用の仕様では、それぞれ強調すべきことが違い、当社は最も大きな書類ではなく、正しい書類を送りたいと考えています。

扉の加工は別の依頼

HYDEについて、掲載している扉加工用のSVGの数は0です。寸法入りの製品外観図は、箱錠の掘り込み全体、角芯とシリンダーの穴、フロントの彫り込み、固定位置を指定するものではありません。扉の加工業者が加工用のテンプレートを必要とするなら、正確な型番と構成について、メーカーが承認した図面を求めるか、加工前に実物のサンプルに対して必要な寸法を書面で確認してください。

欠けている加工寸法を、製品のSVGを拡大縮小して導き出さないでください。寸法が掲載されていないところは、工場への未解決の質問として扱ってください。

扉の加工業者が通常必要とするのは短いリストで、依頼と一緒に送る価値があります。箱錠なら、ケースの高さ、幅、奥行き、フロントの長さ、幅、厚さと角の形状、バックセット、芯々距離、角芯のサイズ、シリンダーまたは鍵穴の位置。チューブラー錠や本締錠なら、面の穴径、小口の穴径、バックセット、扉厚の範囲。当社の仕様表ですでに掲載している行は、お客様の構成に対して書面で確認します。空欄の行は、推定せずに工場に持ち帰ります。

どの書類をどの承認図書に入れるか

同じ製品でも、誰が読むかによって4種類の異なる書類が必要になることがあり、正しいものを送れば指摘のやり取りが1回減ります。

施主や建築家の承認には、製品写真、仕様表、仕上げ、機能が必要です。扉メーカーには、正確な型番について確認済みの取付形状が必要です。製品のSVGは質問を組み立てる助けにはなっても、加工用テンプレートにはなりません。入札には、見積もりに使える仕様の行が必要です。コンプライアンスの審査担当者には、試験書類の発行機関、番号、日付、対象の型番、そして必要な場合は正規の経路を通じた書類そのものが必要です。

承認図書の遅れのほとんどは、正しい書類ではなく最も大きな書類を送ることから生まれます。図面1枚が求められていたのにカタログ全体を送る、適用範囲の行が求められていたのに写真を送る、といったことです。

1つの承認図書で複数の読み手に対応しなければならない場合は、1つに結合したPDFではなく、型番と用途で名前を付けた別々のファイルとして送ってください。試験の適用範囲だけが必要な審査担当者は数秒で見つけられ、後の改訂ではパッケージ全体を再発行せずにファイル1つを差し替えられます。各読み手が、承認の中で自分の担当部分に関わるファイルだけを転送することもできます。

当社の図面をお客様自身のCADやBIMのオブジェクトにする

BIMライブラリがないので、必要なオブジェクトを具体的にしてください。SVGの製品外観図は、単位、縮尺、そして記載された寸法の1つを仕様と照合した後で、CADやモデリングのソフトウェアに取り込めます。裏付けがあるのは、その型番について実際に掲載している寸法だけです。外形線から、隠れた形状、加工のクリアランス、固定穴を推定しないでください。モデル作成者は、確認済みの寸法を使って調整用の簡単な外形を作り、製作用のモデルとして扱う前に残りのデータを求めることができます。

仕様表のパラメーターは、掲載しているものだけを加えてください。仕上げと機能の接尾辞を含む型番、そして掲載があればバックセット、芯々距離、扉厚の範囲です。元の記録が空欄のままにしている値に、金物表は頼れません。

データをまとめて求める

多くの型番の製品ライブラリを作るなら（カタログを立ち上げる代理店や、仕様を標準化するコンサルタントなど）、ページごとではなく、シリーズ全体の仕様の行を表計算のファイルとして求めてください。行はサイトに掲載しているものと同じで、欠けている値も含むので、表計算のファイルでもページとまったく同じ場所に空白が現れます。空白は、隣の型番から埋めるセルではなく、当社に送り返す質問として扱ってください。

そしてお客様の市場が、当社が作っていない書類（特定の形式のBIMオブジェクト、特定の様式の宣言書）を求めているなら、どれを、どの型番について求めているかを教えてください。推測するより、プロジェクトをまたいで何が求められているかを知りたいと考えています。形式と型番を挙げた依頼は、実際に計画を立てられる依頼です。

カタログPDFを最大限に活用する

残っているカタログはスキャンではなくテキストのPDFなので、眺めるだけでなく作業用の書類として使えます。検索してください。型番、バックセット、仕上げコードを入力すれば、それが出てくるすべての場所が見つかり、1つのシリーズ全体を並べて見る最も早い方法です。しおりを使って製品シリーズの間を移動し、型番はわかっているが場所がわからないときは巻末の索引を使ってください。コピーしてください。仕様表は本物のテキストなので、打ち直さずに見積書や金物表に貼り付けられ、打ち直しに伴う転記ミスも起きません。

チームがそういう働き方をしているなら、AIアシスタントに渡すべき書類でもあります。スキャンしたパンフレットは機械にとっては画像の集まりですが、このカタログは読み取り、引用し、サイトと照合できます。スキャンしたパンフレットを併存させずに取り下げたのは、それが理由でした。

当社の書類のダッシュが意味するもの

ここで説明したすべての書類に同じルールが通っていて、1度書いておく価値があります。値が掲載されていないところでは、当社のページ、図面、表計算のファイル、カタログはダッシュを表示するか行を省き、推定値は表示しません。ダッシュは書類の誤りではありません。工場のデータからまだ答えられていない質問で、お問い合わせを送るべき正しい場所です。ダッシュについて尋ねていただければ、出典付きの実測値か、まだわからないという率直な回答が返ってきます。

この記事で1行だけ覚えておくなら、これにしてください。書類は、購入する正確な構成の型番で求め、誰が読むかを伝え、すべてのダッシュを質問として扱うこと。その組み合わせのほうが、「あるものすべて」を求めるより、はるかに多くの場合、最初の返信で正しいファイルを手に入れられます。「すべて」はたいてい、誰かが必要とするより多く、本当に必要だった1つには足りないものです。

Questions this answers

Do you have a BIM library or Revit families?

No. There are no Revit families or IFC objects. Where a model has a dimensioned SVG, we can provide it with the specification as source material for your modeller. Any missing geometry or dimensions must be confirmed before using the result for fabrication.

Can I get a cutsheet or CAD drawing for a model?

There are 84 dimensioned SVG assets for HYDE model slugs among 588 records; 72 appear on the 521 visible product listings. They show supported product dimensions, not complete door-preparation geometry. Check the dimensions needed for your purpose and request missing data. We do not maintain a DWG library per model.

What catalogs are available?

One current HYDE catalog PDF is available. It is a text PDF with searchable specifications, family bookmarks and an index. The older scanned brochure was withdrawn from the download list.

How should a document be requested?

By model number in the configuration you are buying, finish and function suffix included, a drawing of the 60mm (2-3/8") backset version is not a drawing of the 45mm (1-3/4") one. And say what the document is for. A cutsheet for a client approval, a drawing for a door manufacturer's machining setup and a specification for a tender each need a different thing emphasized, and we would rather send the right one than the largest one.

What is a door-preparation drawing?

A door-preparation drawing specifies the geometry a door shop needs for a particular lock and configuration. HYDE currently publishes 0 door-preparation SVGs. The dimensioned product drawings do not establish the full mortise pocket, spindle and cylinder holes, faceplate recess or fixing positions. Ask for confirmed preparation dimensions before machining.

Can I build a BIM or CAD object from your drawings?

A dimensioned SVG can help your modeller create a simple coordination envelope after checking units, scale and the stated dimensions. It does not supply missing geometry or a door-cutting template. Add only verified parameters from the product specification, and confirm any missing dimensions before fabrication.
